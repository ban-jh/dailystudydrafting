# Daily Study 화면 시안

EBS 중학프리미엄의 넓은 상단 탐색, 눈에 띄는 메인 배너, 학년·과목 단위의 콘텐츠 구성을 참고해 Daily Study 흐름에 맞게 다시 구성했습니다. 화면과 구성요소는 Daily Study용으로 새로 작성했습니다. [참고 사이트](https://mid.ebs.co.kr/premium/middle/index)

## 화면

- [메인 화면](main.html): 오늘 배정된 학습과 학교 일정을 우선 표시합니다.
- [학습 화면](learning.html): 핵심 개념, 기초 확인, 기본·심화 문제 선택 흐름을 보여줍니다.
- [로그인 화면](login.html): 학생·학부모 유형 선택과 로그인 폼을 보여줍니다.
- `design.css`: 세 화면이 공유하는 반응형 스타일입니다.

HTML 파일을 브라우저에서 열어 확인할 수 있습니다. 로그인·계정 인증은 시안이므로 실제 계정 데이터를 저장하지 않습니다.
