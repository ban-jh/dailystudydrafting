Daily Study — System Architecture

중·고등학생 학습 보조 플랫폼 | Spring Boot 4.0 + Vue 3 + MariaDB 11 + Redis 7

Backend Stack

  • • Spring Boot 4.0 + JDK 17
  • • MyBatis 4.0.1 (XML Mapper)
  • • Spring Security + JWT (jjwt 0.12.6)
  • • Spring Batch (크롤링 파이프라인)
  • • springdoc-openapi 2.6.0 (Swagger)
  • • JSoup 1.18.1 (HTML 파싱)

Frontend Stack

  • • Vue 3 (Composition API)
  • • Vite 6.x (Build Tool)
  • • Pinia (State Management)
  • • TailwindCSS 3.4.x
  • • Vue Router 4 (History mode)
  • • Axios (HTTP Client)

AI Content Pipeline

  • • GLM-5.2 cloud — 한국어 요약/문제
  • • GPT-4o-mini — 영어/보조/Fallback
  • • PromptTemplateManager (3종 템플릿)
  • • Redis L1 + DB L2 이중 캐싱
  • • Retry 3회 + Exponential Backoff
  • • Rate Limit: 10회/시간, 50회/일

Redis Strategy

  • • AI 응답 캐싱 (TTL 6~24h)
  • • JWT 블랙리스트 (로그아웃)
  • • Rate Limiting (API/AI 호출 제한)
  • • 계정 잠금 (5회 실패 / 30분)
  • • 리더보드 ZSET (주간/월간)
  • • 연속 학습일 / 대시보드 캐시

Security

  • • JWT (Access 24h + Refresh 7d)
  • • OAuth2 (Google, Kakao) — Phase 2
  • • BCrypt (strength=10)
  • • RoleAuthorizationFilter (URL 패턴)
  • • CORS 화이트리스트
  • • Nginx 보안 헤더 + HTTPS

Data & Deployment

  • • MariaDB 11 (12 도메인 테이블)
  • • Docker Compose (4 컨테이너)
  • • Multi-stage Dockerfile (Backend/Frontend)
  • • Nginx Reverse Proxy (SPA + API)
  • • Ubuntu 24.04 LTS
  • • 환경변수 주입 (.env)
