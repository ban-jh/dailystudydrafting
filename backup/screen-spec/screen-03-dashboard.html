이벤트 설명

1환영 메시지
  • 로그인 사용자 이름 + 환영 인사 표시
  • GET /api/users/me 응답 기반 렌더링
  • 현재 시간대에 따라 인사 메시지 변경 (아침/점심/저녁)
2오늘의 추천 학습 카드
  • GET /api/recommendations/today 호출 — AI 추천 알고리즘
  • 사용자 학습 이력, 관심과목, 학년 기반 맞춤 추천
  • 카드 클릭 시 해당 단원 문제 풀이 설정(SCR-07-QUIZ)로 이동
  • 추천 데이터가 없을 경우 "진단 테스트를 먼저 해보세요" 표시
3학습 현황 통계
  • 정답률: GET /api/statistics/accuracy — 오늘 기준
  • 학습시간: GET /api/statistics/study-time — 오늘 누적
  • 스트릭: GET /api/statistics/streak — 연속 학습일
  • 각 항목 클릭 시 학습 통계(SCR-11-STATISTICS)로 이동
4빠른 접근 카드
  • 과목 카드 → 과목 목록(SCR-04-SUBJECTS)
  • 문제풀기 → 문제 풀이 설정(SCR-07-QUIZ)
  • 오답노트 → 오답노트(SCR-09-WRONG-ANSWERS)
  • 영어 → 실생활 영어(SCR-10-ENGLISH)
  • 카드 호버 시 그림자 효과 + 살짝 위로 이동
5오늘의 영어 문장
  • GET /api/english/today 호출 — 오늘의 문장 1개
  • 영어 문장 + 한국어 해석 표시
  • 🔊 버튼 클릭 시 TTS 음성 재생 (Edge TTS / OpenAI TTS)
  • 카드 클릭 시 실생활 영어(SCR-10-ENGLISH)로 이동
  • 사용자 설정의 TTS 자동재생 여부에 따라 자동 재생
