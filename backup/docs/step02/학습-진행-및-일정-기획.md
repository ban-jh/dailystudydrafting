# 학습 진행 단계와 일일·주간 일정 기획

> 상태: AI 학습 설계 검토를 반영한 초안. 실제 교사 검토 전까지 시간·복습 간격·성취 기준은 가설이며 확정 정책이 아닙니다.
>
> 기준일: 2026-11-06

## 1. 목적

중학교 2학년 학생이 교과서 목표를 순서대로 배우고 매일·주간 계획에 따라 새 학습과 복습을 함께 하도록 설계합니다. 권장 흐름은 **선수 개념 확인 → 개념 설명·풀이 예시 → 기억해 내기 → 안내된 기초 연습 → 독립 적용 → 피드백·복습**입니다. 예시는 부안중학교 2026학년도 수학 2 교과서(천재교과서 김화경)의 목차에 나타난 `연립일차방정식과 그 해`를 사용합니다. 실제 목표와 일정은 담당 교사의 확인이 필요합니다.

기존 학생 정보구조의 `오늘의 학습`, `과목·단원별 진도`, `요약 학습`, `오늘의 문제`, `오답 복습`과 관리자 `학습 일정` 흐름을 구체화합니다. 기존 전체 화면 설계와 아키텍처를 대체하는 확정 명세가 아니라 MVP 결정을 위한 제안입니다.

## 2. 학습 단위와 진행 순서

### 2.1 권장 학습 단계

| 순서 | 학생 단계 | 목적 | 연립일차방정식 예시 | 기록/완료 제안 |
|---|---|---|---|---|
| 0 | 선수 개념 확인 | 필요한 선행 지식 단서 확인 | 등식의 성질, 한 문자 일차방정식의 해 | 진단 응답 저장. 점수가 아니라 자료·힌트 선택에 활용 |
| 1 | 개념 설명과 풀이 예시 | 개념을 설명과 예시로 이해 | 두 식을 동시에 만족하는 해와 대입 확인 | 예시의 핵심 단계 질문에 응답 |
| 2 | 기억해 내기와 요점 확인 | 요점을 먼저 떠올린 뒤 정리와 비교 | “연립방정식의 해는 무엇을 만족해야 할까요?” | 회상 응답 후 요점 공개. 열람만으로 이해 판정 안 함 |
| 3 | 안내된 기초 연습 | 힌트와 피드백으로 기본 절차 연습 | 순서쌍을 두 식에 대입해 해인지 확인 | 첫 응답, 힌트·재시도 기록과 설명 제공 |
| 4 | 독립 적용 문제 | 다른 표현이나 맥락에 적용 | 간단한 연립일차방정식의 해 구하고 확인 | 다양한 증거를 수집. 달성 기준은 교사 검토 후 설정 |
| 5 | 마무리·후속 경로 | 활동 완료와 목표 성취를 나눠 안내 | 완료, 추가 연습 권장 또는 복습 예약 | 이력 저장, 오답이면 보충 설명·새 유사 문제 연결 |

각 단계의 콘텐츠는 관찰 가능한 목표와 연결합니다. `읽음/제출함`은 학습 활동 완료이고 `목표 달성`은 서로 다른 문항이나 설명 결과 등 복수 증거에 대한 별도 판단입니다. 한두 문항만으로 숙달을 선언하지 않습니다. 첫 응답 후 피드백을 제공하고, 오답이면 풀이 예시와 새 유사 문항으로 회복하도록 합니다.

### 2.2 학습 세션과 작은 단위

- **과목 → 단원 → 학습 목표 → 학습 세션 → 단계별 콘텐츠** 구조를 사용합니다.
- 한 단원이 길면 여러 세션으로 나눕니다. 예시는 교과서 소단원인 `연립일차방정식과 그 해`, `연립일차방정식의 풀이`를 사용합니다. 목표와 선수 개념은 실제 교과서와 담당 교사가 확인합니다.
- 한 세션 안에 자료·정리·기초·적용을 모두 넣을 수도 있고, 2~5일 계획으로 나누어 배정할 수도 있습니다.
- 학생은 중단한 단계에서 이어서 학습합니다. 하루 계획이 끝나도 다음 날 일정이 사라지지 않으며, 미완료 학습은 `이어하기` 또는 `일정 다시 잡기`로 표시합니다.

## 3. 일정 편성 원칙

### 3.1 일일 일정

학생 홈의 ‘오늘의 학습’에 날짜, 과목, 단원/목표, 단계 진행률, 예상 시간, 시작·이어하기 버튼을 표시합니다. 여러 과목을 배정할 때는 과목별 분량과 합계 예상 시간을 보여주고, 하루 총량이 과도한지 운영자가 미리 확인할 수 있어야 합니다.

### 3.2 주간 일정 예시

아래는 부안중학교 2026학년도 수학 2(천재교과서 김화경) 목차의 연립일차방정식 관련 내용을 이용한 **일정 구조 예시**입니다. 주별 배치와 분량은 실제 학교 진도·학생 반응으로 검증되지 않은 가정입니다.

| 요일 | 학습 목표 예시 | 배정 단계 | 예상 시간 예시 |
|---|---|---|---:|
| 월 | 선수 개념 확인, 연립방정식의 해 의미 | 짧은 진단 → 설명·풀이 예시 | 분량은 학생 파일럿으로 확인 |
| 화 | 순서쌍이 두 식을 만족하는지 판별 | 회상 → 안내된 기초 문제 → 피드백 | 파일럿으로 조정 |
| 수 | 연립일차방정식 풀이 절차 연습 | 전일 회상 → 풀이 예시 → 단계별 연습 | 파일럿으로 조정 |
| 목 | 새로운 계수의 문제에 풀이 적용 | 예약 복습 → 독립 적용 → 풀이 설명 | 파일럿으로 조정 |
| 금 | 주간 누적 확인과 취약 목표 보충 | 혼합 확인 → 오류별 보충 → 다음 계획 | 파일럿으로 조정 |

주간 계획 화면은 날짜별 항목과 주간 학습량을 함께 보여줍니다. 일정 유형은 `날짜 고정형`(운영자가 날짜에 콘텐츠를 배정)으로 MVP를 시작하고, 이후 `진도 적응형`(학생 완료 속도에 따라 다음 콘텐츠 날짜가 이동)을 검토합니다. 두 방식을 한 일정에서 혼용하지 않도록 일정 정책을 명시합니다.

### 3.3 일정 상태와 변경

- 일정 상태: 예정, 진행 중, 완료, 미완료, 재배정 필요.
- 일정 변경 시 기존 학습 기록은 보존하고 앞으로의 배정만 수정합니다.
- 휴일·결석·학습 중단은 미완료 항목을 무조건 실패로 표시하지 않고, 이어하기·재배정 정책을 둡니다.
- 반복 학습은 원래 학습과 별도의 복습 일정으로 기록해 진도 통계를 구분합니다.

### 3.4 복습 설계: 새 학습과 복습을 함께 운영

새 단원을 처음 배우는 일정은 **새 학습·진도 학습** 경로이고, 이미 배운 내용을 기억하고 적용하는 복습은 별도 경로로 관리합니다. 복습을 오답노트에서 학생이 직접 찾아야 하는 선택 기능으로만 두지 않고, 오늘 할 일에 짧은 복습을 배정하는 것을 제안합니다.

#### 복습 항목을 만드는 기준

- 새 개념 학습을 완료하면 해당 학습 목표를 복습 대상으로 등록합니다.
- 문제를 틀리거나 힌트를 사용한 문항은 연결된 개념의 복습 후보로 등록합니다. 응답 시간만으로 어려움이나 오개념을 추정하지 않습니다.
- 맞혔더라도 학생이 `헷갈렸어요`를 선택하면 재확인 대상으로 둡니다.
- 자신 있게 맞힌 항목은 복습 간격을 늘리고, 틀리거나 자신 없던 항목은 가까운 시점에 다시 제시합니다.
- 기존 학습·문제 시도 기록은 일정 변경이나 콘텐츠 수정 후에도 보존합니다.

복습 대상은 틀린 문항을 그대로 반복하는 데 그치지 않아야 합니다. 먼저 개념 질문이나 짧은 문제로 기억을 꺼내게 하고, 답변 뒤 정답과 해설을 보여줍니다. 같은 오개념이 반복되면 같은 문항을 더 내는 대신 쉬운 설명이나 예시로 돌아가는 보충 학습을 배정합니다.

#### 복습 주기 시작값

분산된 회상 연습을 포함하는 방향은 연구 및 교육 실천 지침과 부합하지만, 모두에게 적용할 단일 간격은 정해져 있지 않습니다. 아래 간격은 **검증할 정책 후보**이며 교사 확인 전 운영 기본값으로 확정하지 않습니다. 초기 파일럿은 설정 가능한 정책으로 두고 정확도와 지연 회상 결과를 봅니다.

| 복습 결과 | 다음 복습 제안 | 처리 |
|---|---|---|
| 새 학습 완료 | 다음 날 회상 질문을 후보로 예약 | 파일럿에서 사용 적합성 관찰 |
| 정답, 힌트 없이 해결 | 더 늦은 시점 회상 후보로 이동 | 3일·7일은 비교할 후보일 뿐 확정 간격 아님 |
| 오답 또는 힌트 사용 | 풀이 확인 후 새 유사 문항으로 재확인 | 반응을 보고 가까운 복습 여부 판단 |
| 같은 개념에서 반복 오답 | 쉬운 설명·예시를 먼저 제공 | 보충 학습 뒤 유사 문제로 확인 |
| 여러 차례 안정적으로 정답 | 다음 주 또는 단원 마무리 때 확인 | 빈도를 낮추되 누적 확인 기회 유지 |

복습 신호는 첫 응답의 정오, 힌트 사용, 자기 평가처럼 해석 가능한 항목부터 사용합니다. 자기 평가만으로 간격을 정하지 않습니다. 같은 목표의 예약 복습과 오답 복습은 중복을 제거해 하나의 묶음으로 제시합니다. 하루 복습 시간/항목 상한, 지연 항목 우선순위, 연기·이월 정책은 설정 가능하게 하고 파일럿에서 결정합니다. 복습 지연은 새 학습을 자동 차단하지 않습니다. 복습 대상이 없으면 이를 명시하고 새 학습만 제공합니다.

#### 연립일차방정식 주간 예시: 새 학습과 복습 결합

| 요일 | 새 학습 | 함께 배정하는 복습 |
|---|---|---|
| 월 | 연립방정식과 그 해의 의미 | 설명 뒤 해가 만족할 조건 회상 |
| 화 | 순서쌍이 해인지 판별 | 월요일 목표 회상 + 단계별 기초 문제 |
| 수 | 연립일차방정식 풀이 절차 | 해의 의미 재확인 + 전날 오류 보충 |
| 목 | 새로운 수치의 문제에 적용 | 예약 복습 + 독립 적용 문제 |
| 금 | 주간 누적 확인 | 여러 목표 혼합 확인 + 반복 오류 보충 |
| 다음 주 | 다음 진도 | 지연 회상 결과에 따라 재복습 후보 연결 |

이 표는 설계 예시이며 실제 교과서 진도나 해당 학교의 수업 일정은 아닙니다. 복습 유형은 `간격 복습`, `오답 복습`, `주간 누적 복습`, `보충 학습`으로 구분해 학습 기록과 운영 지표에서 따로 확인합니다.

## 4. 화면 구성 제안

### 4.1 학생 화면 흐름

```text
오늘의 학습
  ├─ 오늘의 복습 (예약 복습·오답·누적 확인)
  └─ 오늘의 새 학습
       → 과목/단원 학습 카드 선택
       → 오늘 목표·예상 시간
       → 개념 자료 → 중요 요점
       → 기초 문제 및 즉시 피드백
       → 적용 문제 및 제출 후 해설
       → 완료 요약 / 취약 목표 복습 예약 / 이어하기
```

**오늘의 학습 카드**에는 `수학 · 연립일차방정식과 그 해`, 관찰 가능한 목표, 학생 파일럿으로 산정한 예상 시간, 단계 진행, `이어하기`를 담습니다. 학생은 일정표를 찾아 들어가지 않고 오늘 항목을 시작합니다.

**학습 화면**은 선수 개념을 부담 없이 확인하고 필요하면 보충 예시를 제시합니다. 새 개념 설명과 풀이 예시 뒤에는 요점 공개 전에 학생이 핵심을 먼저 회상하도록 합니다. 기초 문제에는 단계별 힌트와 이유가 담긴 피드백을 제공합니다. 오답이면 풀이 예시 뒤 새 유사 문항으로 회복하게 하고 적용 문제는 첫 응답 전에 정답을 노출하지 않습니다.

**완료 화면**은 완료 단계, 핵심 요점, 정답률 또는 확인 결과, 미완료 항목, 오답 재학습 링크, 다음 일정만 간결히 보여줍니다. 정답률을 유일한 성공 기준으로 삼지 않습니다.

**오늘의 복습 카드**에는 복습 이유(예: `어제 연립방정식의 해 조건 회상`, `지난 문제에서 힌트를 사용함`), 학습 목표, 파일럿으로 산정한 예상 시간, 시작 버튼을 보여줍니다. 먼저 답을 떠올리게 하고 `정답 확인` 후 풀이·해설을 제공합니다. 자기 평가는 기록하되 단독으로 복습 간격을 결정하지 않습니다.

### 4.2 주간 계획 화면

- 상단: 주간 날짜 범위, 총 예상 시간, 완료/예정 요약.
- 본문: 날짜별 `새 학습`과 `복습` 섹션, 과목 카드, 단원·목표, 단계, 상태, 예상 시간.
- 학생 행동: 오늘 항목 시작/이어하기, 미완료 일정 확인, 주간 보기 이동.
- MVP에서는 학생이 학습 목표나 날짜를 임의 변경하지 않고, 필요 시 관리자 정책에 따라 재배정 요청 또는 일정 다시 잡기를 제공합니다.
- 복습 카드에는 원래 학습 날짜와 복습 이유를 표시하고, 복습 완료 상태를 새 학습 상태와 구분합니다.
- 모바일에서는 날짜별 세로 카드, 넓은 화면에서는 주간 열 또는 목록으로 표현합니다. 일정 변경에도 키보드 접근과 상태 텍스트를 유지합니다.

### 4.3 관리자 일정 편성 화면

관리자는 학교·학년·과목·단원·기간을 선택하고 주간 달력에 새 학습 세션과 공통 복습 항목을 배치할 수 있습니다. 학생 반응에 따라 자동 생성되는 개인 복습은 고정 주간 계획과 구분합니다. 목표, 예상 시간, 단계 콘텐츠 연결, 난이도, 검수 상태를 확인하고, 게시 전 누락 단계·미검수 콘텐츠·하루 분량 초과·날짜 중복을 경고합니다. 일정 초안 → 검토 → 게시 → 변경 이력 순서로 운영합니다.

## 5. 요구사항 초안과 완료 판단

### 학생 기능

1. 오늘·주간 일정을 조회하고 날짜별 학습 상태를 확인한다.
2. 오늘 학습을 시작하거나 마지막 미완료 단계에서 이어간다.
3. 각 단계의 진행 상태가 저장되어 앱을 다시 열어도 이어진다.
4. 기초 문제의 피드백과 적용 문제의 제출 후 해설을 확인한다.
5. 미완료 학습과 오답을 후속 학습으로 안내받는다.
6. 예약 복습과 취약 항목 복습을 새 학습과 구분해 수행한다.
7. 복습 결과에 따라 다음 복습 시점과 활동 유형이 조정된다.

### 일정·콘텐츠 운영 기능

1. 관리자는 승인된 콘텐츠만 일정에 게시할 수 있다.
2. 일정은 과목·단원·목표·날짜·대상 학년·콘텐츠와 연결된다.
3. 일일/주간 계획에서 예상 분량과 콘텐츠 누락을 게시 전에 확인한다.
4. 게시 후 수정은 변경 이력에 남고, 이미 완료한 학생 기록을 보존한다.
5. 고정 주간 복습과 개인 반응에 따른 복습을 구분하며, 하루 복습 분량 상한을 설정할 수 있다.

### 학습 완료 정의 제안

- 단계 완료는 해당 단계의 필수 콘텐츠를 확인하거나 제출한 상태로 기록합니다.
- 세션 완료는 필수 단계 완료와 마지막 확인 활동 제출을 만족하면 기록합니다.
- 활동 완료와 학습 목표 달성 판단은 별도 상태로 기록합니다. 오답이 있어도 학습 활동을 마칠 수 있습니다. 목표 달성은 서로 다른 문항·설명 결과 등 복수 증거를 교사가 정한 기준으로 확인하며, 초기에는 한두 문항만으로 숙달을 선언하지 않습니다.
- 증거가 아직 부족하면 `추가 확인 필요`로 표시하고 다음 회상 또는 적용 문항을 연결합니다. 답을 맞혔는지만으로 학생의 이해를 확정하지 않습니다.
- 기준은 콘텐츠 유형별로 달라질 수 있으므로 요구사항 단계에서 요약 읽기, 영상, 퀴즈 각각의 완료 조건을 확정합니다.

## 6. 개발을 위한 단계별 프로세스

| 순서 | 작업 | 주요 산출물 | 통과 조건 |
|---|---|---|---|
| 1. 학습 정책 | 대상 학년·과목·단원·목표·세션 분량과 일일/주간 편성 정책을 결정 | 학습 흐름 정책, 주간 예시 | 실제 수업 진도와 서비스 일정의 책임 주체를 결정 |
| 2. 콘텐츠 모델 | 관찰 가능한 목표, 선수 개념, 풀이 예시, 회상·연습·피드백, 출처·난이도·검수 상태 정의 | 콘텐츠 필드 명세, 교사 확인된 수학 샘플 | 목표-문항 연결과 풀이·정답·출처 검수 완료 |
| 3. 사용자 여정·화면 | 학생 오늘→학습→문제→완료, 주간 계획, 관리자 편성 흐름 작성 | 사용자 흐름도, 와이어프레임, 빈/오류 상태 | 학생이 다음 행동을 이해하고 미완료 학습을 이어갈 수 있음 |
| 4. 요구사항·인수 기준 | 화면·일정·학습 상태의 정상/예외 동작과 권한을 정리 | 기능 요구사항, 인수 기준 | 일정 변경·오프라인/로드 실패·미완료 상황 정의 |
| 5. 데이터/API 설계 | 과목·단원·세션·단계 콘텐츠·일정·배정·학습 기록 관계 정의 | ERD, API 명세, 상태 전이 | 날짜/시간대, 중복 배정, 콘텐츠 버전 변경 정책 확인 |
| 6. 수직 슬라이스 구현 | 한 학생이 교과서 기반 수학 목표를 학습하고 후속 복습까지 마치는 과정 구현 | 실행 가능한 학생 흐름, 관리자 최소 등록·배정 | 교사 확인 콘텐츠로 학습·복습 흐름 완주 |
| 7. 검증·개선 | 화면 사용성, 콘텐츠 정확성, 일정 예외, 저장·권한을 확인 | 검증 기록, 수정 목록 | 학생이 과제와 다음 행동을 이해하고 기록이 유실되지 않음 |
| 8. 제한 공개 준비 | 콘텐츠 운영, 모니터링, 문의/오류 처리, 운영 일정 준비 | 운영 체크리스트, 콘텐츠 공급 계획 | 공개 기간 동안 일정과 검수 담당자가 정해짐 |

개발은 **연립일차방정식 한 목표의 새 학습과 후속 복습**을 기준으로 콘텐츠 등록→일정 배정→선수 확인→회상/연습→복습 생성→결과 반영을 연결하는 수직 슬라이스로 진행합니다. 복습 간격은 코드에 고정하지 않고 정책 설정으로 분리합니다.

## 7. MVP 범위 제안

### 우선 포함

- 중2 한 과목·한 단원 샘플 학습 콘텐츠.
- 학생 오늘 일정과 이어하기.
- 선수 확인 → 설명·풀이 예시 → 회상 → 안내 연습 → 독립 적용 → 피드백 흐름.
- 간단한 주간 계획 조회.
- 학습 완료·오답·자기 평가에 따른 기본 복습 예약 및 오늘 복습 카드.
- 관리자의 콘텐츠 연결·검수 상태 확인·날짜 배정·게시.
- 학습 단계별 진행, 문제 결과 및 복습 이력 기록.

### 후속 검토

- 학생별 진도에 따른 자동 일정 재편성.
- AI가 학생의 취약점에 따라 콘텐츠와 난이도를 자동 추천.
- 반복 간격 최적화, 연속 출석 보상, 보호자 알림.
- 여러 학교의 서로 다른 수업 진도를 자동 반영.

초기 검증에서는 자동화된 개인화보다 교사 확인 콘텐츠와 설정 가능한 복습 정책을 먼저 제공합니다. 학습 목표별 첫 응답 결과, 힌트·재시도 사용, 일정 간격 뒤 회상 결과, 다른 형태 문항의 적용 결과, 학생의 체감 분량을 살핍니다. 문항 판본과 노출 시점도 기록해 결과 해석에 활용합니다.

## 8. 미결정 사항

1. 하루 학습 시간을 몇 분으로 설정하고, 하루에 몇 과목까지 배정할지.
2. 주간 계획을 운영자가 고정할지, 학생의 완료 속도에 따라 이동시킬지.
3. 학습 자료의 형식(텍스트, 영상, 음성, 상호작용)과 각 단계 필수 여부.
4. 기초·적용 문제 수, 재시도 정책, 통과 기준, 해설 노출 시점.
5. 미완료·결석·휴일·학습 일정 변경의 처리 원칙.
6. 학생이 일정 재배정을 직접 요청할 수 있는지.
7. 학교 실제 진도와 교과서 단원 정보를 누가 확인·입력·승인할지.
8. 보호자에게 공유할 진도와 성취 정보의 범위.
9. 콘텐츠의 출처·저작권·검수 기준 및 운영 담당자.
10. 복습 주기 시작값, 하루 복습 시간/항목 수 상한, 간격 조정 기준.
11. 오래된 미완료 복습과 오늘 새 학습이 겹칠 때의 우선순위.

## 9. 검토 결과와 참고 자료

- 교육부 고시에 따라 2026학년도에 중학교 2학년은 2022 개정 교육과정을 적용합니다: [교육부 2022 개정 교육과정 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0).
