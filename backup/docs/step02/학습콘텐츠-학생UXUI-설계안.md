# 학습 콘텐츠·학생 UX/UI 설계안

> 상태: 교육 설계 검토 기록을 반영한 설계 초안. 화면 예시와 수학 콘텐츠는 교사 검토 및 학생 사용성 확인 전까지 확정안이 아닙니다.
>
> 기준 자료: [교육설계 검토 및 수정 기록](교육설계-검토-및-수정기록.md), [학습 진행·일정 기획](학습-진행-및-일정-기획.md), [관리자·학생 화면 상세 기획](관리자-학생-화면-상세기획.md)

## 1. 설계 목표

학생이 부담 없이 시작하고, 답을 먼저 떠올려 보고, 막히면 도움을 받아 다시 시도하며, 학습 후 무엇을 할지 알 수 있게 합니다. 재미 요소는 점수 경쟁보다 **짧은 도전, 선택권, 분명한 진전, 이해를 돕는 피드백**에서 만듭니다.

### 학습 전문가 관점

- 한 세션은 관찰 가능한 학습 목표 하나에 집중합니다.
- 선수 개념을 낮은 부담으로 확인하고, 결과에 따라 짧은 보충 설명을 제안합니다. 진단 응답은 성적처럼 표시하지 않습니다.
- 설명과 풀이 예시를 본 뒤 학생이 먼저 기억을 꺼내고, 안내 연습에서 독립 적용으로 넘어갑니다.
- 오답은 실패 표시로 끝내지 않고, 생각 단서 → 단계별 힌트 → 풀이 설명 → 새로운 유사 문제 순서로 회복시킵니다.
- 활동 완료와 목표 달성을 구분합니다. 한두 문제를 맞힌 것만으로 숙달을 선언하지 않습니다.

### 웹 기획·UX/UI 관점

- 첫 화면에는 오늘 할 일과 바로 시작할 버튼을 우선 배치합니다.
- 한 화면에서 한 가지 학습 행동만 요청하고, 단계 수와 현재 위치를 계속 보여줍니다.
- 학생에게 일정 관리 부담을 주지 않습니다. 오늘 계획은 간단히 제시하고, 미완료는 비난 없이 이어하기로 안내합니다.
- 색상만으로 정답·상태를 전달하지 않고 텍스트와 아이콘을 함께 사용합니다. 키보드 조작, 모바일 화면, 읽기 쉬운 글자 크기를 지원합니다.
- 연속 출석 끊김, 순위표, 공개 점수 비교, 시간 압박은 사용하지 않습니다.

## 2. 대표 세션 콘텐츠 설계

**대상 예시:** 중학교 2학년 수학  
**단원 예시:** 연립일차방정식과 그 해  
**학습 목표:** 주어진 순서쌍을 두 식에 대입하여 연립일차방정식의 해인지 판별한다.  
**성공 증거:** 첫 응답, 두 식을 확인한 풀이 또는 설명, 다른 수치 문항에의 적용을 함께 본다. 정답 개수 하나만으로 목표 달성을 판단하지 않는다.

| 단계 | 학생에게 보여줄 콘텐츠 예시 | 상호작용과 피드백 |
|---|---|---|
| 1. 가볍게 준비 | “출발 전 확인! 등식에서 양쪽에 같은 수를 더하면 등식은 어떻게 될까요?” | 선택 응답. 정오에 따라 선수 설명을 보여주되 점수·등급은 붙이지 않음 |
| 2. 개념 보기 | “연립방정식의 해는 두 식을 모두 참으로 만드는 순서쌍이에요.” `x+y=5`, `x-y=1`에 `(3,2)`를 대입해 보기 | 식마다 대입 결과를 한 줄씩 표시. 학생이 직접 값 확인 버튼을 누를 수 있음 |
| 3. 먼저 떠올리기 | “정리 카드를 잠깐 덮어 둘게요. 해가 되려면 무엇을 확인해야 할까요?” | 짧은 답 입력 또는 선택 후 핵심 요점 공개. 열람만으로 이해 처리하지 않음 |
| 4. 함께 풀기 | “(4,1)은 해일까요? 첫 번째 식부터 확인해 보세요.” | 첫 힌트: `x와 y를 첫 번째 식에 넣어 보세요.` 다음 힌트: `4+1의 값은 오른쪽과 같나요?` 필요할 때 한 단계씩 공개 |
| 5. 혼자 적용 | “x+y=6, x-y=2에서 (4,2)는 해일까요? 두 식을 각각 확인해 보세요.” | 정답 제출 전 풀이 숨김. 오답이면 어느 식에서 막혔는지 짚고, 설명 뒤 다른 수치의 새 문제 제공 |
| 6. 마무리 | “오늘은 두 식을 모두 확인하는 방법을 연습했어요.” “다음에는 새 문제로 한 번 더 확인해요.” | 완료한 활동과 추가 확인이 필요한 목표를 구분. 오답은 복습 링크로 이어짐 |

문항의 수학적 정확성, 어휘 난이도, 오개념을 유발하지 않는 힌트는 실제 교사가 확인해야 합니다. 위 문항은 화면 설계를 위한 샘플입니다.

## 3. 학생 UX/UI 화면 흐름

```text
오늘
  → 오늘 할 학습 카드 선택
  → 목표와 단계 미리 보기
  → 선수 확인
  → 개념·풀이 예시
  → 먼저 회상
  → 힌트가 있는 연습
  → 독립 적용
  → 결과와 이어 할 학습
```

### 오늘 화면

- 상단: 짧은 인사와 오늘 날짜, “오늘은 2개를 차근차근 해봐요” 같은 부담 없는 안내.
- 첫 카드: 새 학습 또는 복습을 구분하고, 과목·목표·학습 이유를 한 줄로 표시.
- 버튼: 진행 중이면 `이어서 하기`, 새 항목이면 `시작하기`로 단순화.
- 분량: 파일럿으로 확인하기 전까지 예상 시간은 확정 숫자로 약속하지 않습니다.
- 미완료 상태: `아직 남아 있어요. 여기서 이어서 할 수 있어요.`처럼 낙인 없이 안내합니다.

### 학습 화면

- 상단에 `3/6 단계`와 단계 이름을 표시하고, 완료된 단계와 남은 단계를 함께 보여줍니다.
- 본문에는 설명, 질문, 답변 선택지 등 현재 행동만 둡니다. 보조 자료는 펼쳐서 봅니다.
- 주 행동 버튼은 한 개를 강조합니다. 예: `답 확인하기`, `다음 문제`, `계속하기`.
- 힌트는 한 번에 모두 공개하지 않고 학생이 선택해 단계별로 봅니다.
- 피드백은 정오 표시와 함께 이유 및 다음 행동을 제공합니다. 예: “첫 번째 식은 맞아요. 두 번째 식도 확인해 볼까요?”
- 잠시 나가도 응답과 현재 단계가 저장된다는 점을 보여줍니다.

### 결과 화면

- “완료한 활동”과 “다음에 다시 확인할 목표”를 분리합니다.
- 학습 결과는 구체적인 행동으로 설명합니다. 예: `두 식에 대입해 확인했어요`, `다음에는 다른 순서쌍으로 한 번 더 연습해요`.
- 다음 행동은 `복습 시작` 또는 `오늘 학습으로 돌아가기`처럼 명확히 제시합니다.
- 점수·연속 기록·비교 순위를 사용해 학생을 압박하지 않습니다.

## 4. 재미와 학습 효과를 함께 높이는 장치

| 장치 | 적용 방법 | 학습상 역할 |
|---|---|---|
| 짧은 미션 문구 | “두 식을 모두 만족하는 짝을 찾아보세요”처럼 목표를 행동으로 표현 | 시작할 과제를 분명히 함 |
| 작은 선택권 | 먼저 풀 문제 또는 힌트 보기 여부를 제한된 범위에서 선택 | 학생의 주도감 제공. 핵심 목표와 순서는 유지 |
| 단계별 힌트 | 한 번에 답을 알려주지 않고 다음 생각 단서를 제공 | 스스로 시도할 기회와 적절한 발판 제공 |
| 즉시 설명 피드백 | 맞고 틀림에 그치지 않고 풀이의 어느 조건을 확인할지 알려줌 | 오개념 수정 및 재시도 지원 |
| 눈에 보이는 진전 | 단계 수, 완료한 행동, 다음 활동을 보여줌 | 성적 비교 없이 진행감을 제공 |
| 다양한 표현 | 식, 짧은 문장, 표나 수직선 등 목표에 맞는 표현을 사용 | 같은 개념을 다른 방식으로 이해하고 적용 |

애니메이션과 보상은 이해를 돕거나 학습 완료를 축하하는 짧은 장식으로만 사용합니다. 정답 속도나 연속 접속을 보상 기준으로 삼지 않습니다.

## 5. 성인용 모니터링과 학생 경험의 경계

- 학생 화면은 학습과 다음 행동에 집중합니다.
- 학부모·교사 화면에서는 계획 대비 진행, 완료한 학습, 학습 기록, 반복적으로 도움이 필요한 목표를 확인할 수 있습니다.
- 학부모에게는 단순 점수보다 `무엇을 학습했고 어디서 도움이 필요한지`를 보여줍니다.
- 학생의 자기 평가는 학습 지원 신호로 사용하며 성적처럼 공개하지 않습니다.
- 학생 데이터는 역할별로 필요한 범위만 공유하고, 상세 풀이 기록의 노출 권한은 별도 정책으로 정합니다.

## 6. 파일럿에서 확인할 항목

- 학생이 첫 화면에서 오늘 할 학습과 시작 방법을 이해하는가.
- 학생이 힌트를 적절히 사용하고, 오답 뒤 새 문제에 다시 도전하는가.
- 단계별 이탈, 첫 응답 결과, 힌트·재시도, 일정 간격 뒤 회상, 다른 문항에의 적용을 함께 볼 수 있는가.
- 학생이 느낀 난이도와 실제 소요 시간이 적절한가.
- 콘텐츠와 화면 문구가 실제 중2 학생에게 자연스럽고 정확한가.

파일럿 전에는 학습 시간, 복습 간격, 목표 달성 기준을 확정하지 않습니다. 결과는 학생별 낙인이나 순위가 아니라 콘텐츠·분량·설명을 개선하는 데 사용합니다.
