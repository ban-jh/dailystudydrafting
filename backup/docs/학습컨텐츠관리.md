# 학습 컨테츠 관리 
## 프로세스
```
* 관리자
학교 -> 학년 -> 학기 -> 과목 -> 과목별 목차 (최대 3Depth 까지 ) -> 목차별 설명/요약 노트 작성 / 기초 문제 -> 기본 / 심화 문제 -> 문제 맵핑 -> 일자별 스케줄 작성 (휴일및 시험기간은 제외)

* 학생
- 오늘의 학습 : 과목 선택 -> 설명 노트 -> 기초문제 풀이 -> 단원 기본 문제 -> 단원 심화 문제
- 단원별 문제풀이 (중간고사 기말고사등을 위한 문제 풀이 과정)
```

*  기초문제 : 설명 후 설명을 바탕으로 간단한 문제 풀이
*  기본문제 : 기본 문제 보다 난이도는 있으나 내용을 알면 무난하게 풀수 있는 문제
*  심화문제 : 복합적으로 난이도가 있는 문제

## 학습 성취 정책
학생 진행 현황은 **문항 풀이 진척률, 가중 성취도, 예약 복습 완료율**을 서로 다른 지표로 표시한다. 세 지표는 학교·학년도·학년·과목·학습 일정·조회 기간에 해당하는 게시된 학습 기록을 기준으로 집계한다. 초안, 취소된 배정, 중복 전송된 기록은 집계하지 않는다.

### 문항 풀이 진척률
- 산식: `풀이 진척률 = 제출한 고유 배정 문항 수 ÷ 유효 배정 문항 수 × 100`.
- 유효 배정 문항은 조회 범위 안의 게시된 학습 일정에서 학생에게 배정된 문제를 뜻한다. 풀이 완료는 정답 여부와 관계없이 답안을 제출한 상태로 본다.
- 같은 배정 문항을 여러 번 제출해도 진척률에는 한 번만 반영한다. 게시 후 제외·취소된 문항은 분모에서 제외한다.
- 아직 배정 문항이 없거나 풀이 기록이 없으면 0%로 오인되지 않도록 `측정 전` 또는 `자료 없음`으로 표시한다.

### 가중 성취도
- 성취도는 문제 풀이 결과로 산출하며, 기초·기본·심화 문제에 각각 가중치를 적용한다.
  - 기초 문제 정답률: 30%
  - 기본 문제 정답률: 40%
  - 심화 문제 정답률: 30%
- 산식: `가중 성취도 = 기초 정답률 × 0.30 + 기본 정답률 × 0.40 + 심화 정답률 × 0.30`.
- 단계별 정답률은 `해당 단계에서 첫 답안을 제출한 고유 문항 중 정답 문항 수 ÷ 첫 답안을 제출한 고유 문항 수 × 100`으로 계산한다. 재시도 기록은 학습 과정 분석에 보존하되, 정답률을 높이기 위한 중복 정답으로 성취도를 계산하지 않는다.
- 각 단계의 문항 수를 분모로 사용하므로 문항별 정오답 기록과 단계별 풀이 문항 수를 함께 보관한다. 아직 풀지 않은 문항은 풀이 진척률에는 미완료로 반영하고, 해당 단계 정답률의 분모에는 포함하지 않는다.
- 조회 범위에서 해당 단계의 풀이 기록이 없으면 그 단계 점수를 임의로 0점 처리하지 않는다. 세 단계 중 하나라도 풀이 기록이 없는 경우 가중 성취도는 `측정 전`으로 표시하고, 단계별 기록이 충분한 경우에만 산출한다.
- 그룹 집계는 학생별 정답 수와 첫 제출 문항 수를 단계별로 합산해 정답률을 계산한다. 학생별 화면은 해당 학생의 기록만 사용한다. 단일 성취도만으로 숙달을 확정하거나 학생을 서열화하지 않는다.

### 예약 복습 완료율
- 산식: `예약 복습 완료율 = 기간 종료 시점까지 완료한 예약 복습 수 ÷ 조회 기간에 예정된 유효 예약 복습 수 × 100`.
- 분모는 조회 기간 안에 예정일이 있는 게시된 예약 복습이다. 예정일이 지났지만 완료되지 않은 복습은 미완료로 포함하며, 취소 또는 학생 배정 해제된 복습은 제외한다.
- 완료는 복습 활동에서 연결된 문항 풀이를 제출해 완료 상태로 저장한 경우로 본다. 정답 여부는 완료 판단과 분리하고, 정답 결과는 가중 성취도에 반영한다.
- 반복 제출은 같은 복습 배정의 완료 건수를 늘리지 않는다. 기한이 지난 미완료 복습은 완료율과 별도로 `지연 복습` 건수로 표시한다. 예약 건이 없으면 0% 대신 `예약 없음`으로 표시한다.
