3.3 아키텍처
전체 아키텍처 개요

Daily Study는 클라이언트-서버 분리 아키텍처를 채택하며, 프론트엔드(Vue 3 SPA)와 백엔드(Spring Boot REST API)가 Nginx 리버스 프록시를 통해 통신한다. 모든 컴포넌트는 Docker Compose로 컨테이너화되어 단일 서버에 배포되며, 외부 AI API(GLM-5.2, GPT-4o-mini)를 호출하여 콘텐츠를 동적으로 생성한다.

계층구성 요소주요 역할
PresentationVue 3 SPA, PWA사용자 인터페이스, 오프라인 지원
ProxyNginx리버스 프록시, 정적 파일 서빙, SSL
ApplicationSpring Boot 4.0 REST API비즈니스 로직, 인증, AI 연동
Data AccessMyBatisSQL 매핑, 트랜잭션 관리
Data StoreMariaDB 11, Redis영구 저장, 캐싱/세션
ExternalGLM-5.2, GPT-4o-mini, TTS, OAuth2AI 콘텐츠 생성, 음원, 소셜 인증
BatchSpring Batch, Jsoup, Selenium크롤링 자동화, 통계 집계
InfrastructureUbuntu 24.04, Docker Compose컨테이너 오케스트레이션

SECTION 04
4. Callflow
4.1 AI 문제 출제 프로세스
Step Caller Callee 메시지 / 처리 내용
1ClientNginxPOST /api/quiz/generate (unit_id, difficulty, type, count)
2NginxQuizController요청 전달 (Reverse Proxy)
3QuizControllerAiQuizGenerator단원 정보 조회 (UnitMapper → MariaDB)
4AiQuizGeneratorGLM-5.2 API프롬프트 생성 및 AI 호출 (단원/난이도/유형/문제 수)
5GLM-5.2AiQuizGeneratorJSON 응답 (문제/선택지/정답/해설)
6AiQuizGeneratorReviewQueueService생성 콘텐츠 품질 검수 큐 등록 (status=pending)
7QuizControllerClient생성된 문제 리스트 응답 (200 OK)
8ClientQuizControllerPOST /api/quiz/attempt (사용자 답안 제출)
9GradingServiceMariaDBQUIZ_ATTEMPT 저장, 정답 여부 판정
10WrongNoteServiceMariaDB오답시 오답노트 자동 등록
11StreakServiceRedis연속 학습일 업데이트
12Client—채점 결과 + 해설 표시
4.2 실생활 영어 문장 수집 및 정제 프로세스
Step Caller Callee 메시지 / 처리 내용
1Spring BatchCrawlingJob크롤링 배치 작업 시작 (크론 스케줄러)
2CrawlingJobJsoup / Selenium타겟 사이트 접속 및 문장 수집
3CrawlingJobMariaDB수집 원문 임시 저장 (ENGLISH_SENTENCE, status=raw)
4CrawlingJobGPT-4o-mini문장 정제 요청 (문법 검증, 자연스러움, 난이도 분류)
5GPT-4o-miniCrawlingJob정제된 문장 + 한국어 번역 + 난이도 반환
6CrawlingJobTtsServiceTTS API 호출 (영어 발음 음원 생성)
7TtsServiceCrawlingJob음원 파일 URL 반환
8CrawlingJobMariaDB정제 문장 저장 (status=review_pending, tts_url)
9AdminReviewQueueService관리자 검수 큐에서 승인/반려
10ReviewQueueMariaDB승인 시 status=published — 사용자 노출
4.4 관리자 문제 직접 등록 프로세스
Step Caller Callee 메시지 / 처리 내용
1AdminClient관리자 페이지 → 문제 직접 등록 화면 진입
2ClientSubjectControllerGET /api/subjects — 과목·단원 목록 조회
3AdminClient문제 유형(객관식/주관식/서술형), 난이도, 문제/선택지/정답/해설 입력
4ClientQuizControllerPOST /api/admin/quizzes — 문제 등록 요청 (source_type=MANUAL)
5QuizControllerQuizService문제 유효성 검증 (필수 필드, 선택지/정답 일치성)
6QuizServiceMariaDBQUIZ + QUIZ_OPTION 테이블 저장 (status=DRAFT 또는 PUBLISHED)
7QuizControllerClient등록 성공 응답 (201 Created, quiz_id)
8aAdminClient[즉시 배포] status=PUBLISHED — 학생 화면에 즉시 노출
8bAdminReviewQueue[검수 큐 전달] status=DRAFT — AI 검수 큐에서 추가 검수 진행
Excel/CSV 일괄 업로드: POST /api/admin/quizzes/batch — 파일 업로드 후 백그라운드에서 파싱 및 일괄 저장. 처리 결과(성공/실패 건수)를 응답.
4.3 소셜 로그인 (OAuth2) 프로세스
Step Caller Callee 메시지 / 처리 내용
1ClientAuthControllerGET /api/auth/oauth2/{provider} (google/kakao/naver)
2AuthControllerOAuth2 Provider302 Redirect — 인가 코드 요청
3ClientOAuth2 Provider사용자 로그인 및 권한 동의
4OAuth2 ProviderAuthControllerRedirect with authorization code
5AuthServiceOAuth2 ProviderAuthorization Code → Access Token 교환
6AuthServiceOAuth2 ProviderAccess Token → 사용자 프로필 조회 (email, name)
7AuthServiceMariaDBUSER 테이블 조회/생성 (기존 회원 여부 확인)
8AuthServiceJwtUtilJWT 토큰 발급 (access + refresh)
9AuthControllerClientJWT 토큰 + 사용자 정보 응답
10Client—토큰 저장 (LocalStorage), 대시보드 이동
