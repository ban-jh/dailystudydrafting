# Daily Study 파일럿 웹 화면 기획

- 기준 기획: [10_dailystudy기획.md](10_dailystudy기획.md)
- 화면 배치 시안: [11_화면와이어프레임.html](11_화면와이어프레임.html)
- 목표: 초기 파일럿은 학생의 학습과 문제 풀이에 집중하고, 학부모와 관리자는 필요한 최소 기능만 제공한다.

## 1. 파일럿 범위

| 사용자 | 제공 기능 | 파일럿에서 제외 |
|---|---|---|
| 학생 | 오늘의 학습 콘텐츠 자동 제공, 과목·챕터 선택, 문제 풀이, 채점 결과 확인, 학교·학년 정보 관리, 학교 휴일·개인 학습 일정·중간/기말고사 일정 관리 | 진도율, 학습 통계/리포트, 시험 대비 모드, 랭킹, 복잡한 목표 관리 |
| 학부모 | 자녀가 푼 과목·챕터, 풀이 날짜, 점수 확인 | 진도율, 학습시간 분석, 세부 답안/오답 분석, 계획 편집, 성적 예측 |
| 관리자 | 과목·챕터·학습자료·문제 관리, AI 콘텐츠 준비 상태 확인, 일일 학습 스케줄 편성·운영, 시스템 기준정보와 사용자 관리 | 고급 분석, 다기관/교사 기능 |

파일럿 화면에서는 진도율 숫자·그래프·배지·연속 학습일을 표시하지 않는다. 학생 학습 결과를 기록하는 최소한의 이력은 학부모 점수 조회와 운영에 필요한 범위로만 저장한다.

## 2. 공통 웹 구성

- 로그인 후 사용자 역할에 맞는 첫 화면으로 이동한다.
- 상단에는 서비스명, 현재 로그인 사용자, 계정 메뉴를 둔다.
- 상단 사용자명을 클릭하면 `개인정보 수정`과 `로그아웃` 메뉴를 표시한다. 학생 화면에서 `개인정보 수정`을 선택하면 `학생 07. 학생 정보` 화면으로 이동한다.
- 학생 메뉴: `학습 홈`, `과목 선택`, `내 학습 결과`, `학생 정보`, `학습 일정`
- 학부모 메뉴: `자녀 학습 결과`, `계정 설정`
- 관리자 메뉴: `학습 정보`, `일일 학습 스케줄`, `서비스 설정`, `공통코드 관리`, `메뉴 관리`, `메뉴 권한 관리`, `공휴일 관리`, `사용자 관리`
- 로그인한 학생에게는 관리자 스케줄에 따라 해당 날짜에 배정된 학습 콘텐츠를 학습 홈에 자동으로 표시한다. 학생은 별도 일정 편집 기능 없이 오늘의 학습을 시작할 수 있다.
- 일일 학습 스케줄은 AI가 필요한 학습 정보 콘텐츠를 생성하고, 필수 구성요소가 완료되며 관리자 검수·승인을 받은 콘텐츠만 편성할 수 있다. 준비되지 않은 콘텐츠는 스케줄에 추가하거나 학생에게 노출하지 않는다.
- 학생은 `학생 정보`에서 학교와 학년을 관리하고, `학습 일정`에서 학교 휴일과 시험 일정을 등록하며 개인 학습 날짜·시간을 조정할 수 있다. 일정 조정은 학습 콘텐츠의 내용이나 관리자 승인 상태를 바꾸지 않는다.
- 모바일에서는 메뉴를 접이식 내비게이션으로 바꾸고 문제 풀이 화면을 우선 배치한다.

## 3. 로그인 및 회원 화면

| Index | 화면 제목 | 배치할 콘텐츠와 기능 |
|---|---|---|
| 01 | 로그인 | 아이디 또는 이메일, 비밀번호, 사용자 유형(학생/학부모), 로그인 버튼을 제공한다. 학생·학부모 회원가입, 아이디 찾기, 비밀번호 찾기로 이동하는 링크를 둔다. |
| 02 | 학생 회원가입 | 이름, 아이디/이메일, 비밀번호와 확인, 학교명, 학교급·학년을 입력한다. 약관 동의 후 학생 계정을 신청한다. |
| 03 | 학부모 회원가입 | 이름, 아이디/이메일, 비밀번호와 확인, 연락처를 입력하고 약관에 동의해 보호자 계정을 신청한다. 가입 후 자녀 초대 코드로 연결할 수 있도록 안내한다. |
| 04 | 아이디 찾기 | 가입자 이름과 가입 이메일 또는 연락처를 입력하고 본인 확인 후 아이디를 확인한다. 화면에는 아이디 일부를 마스킹해 표시한다. |
| 05 | 비밀번호 찾기 | 아이디/이메일과 가입 연락처를 확인하고 인증 후 새 비밀번호와 확인 값을 입력해 재설정한다. |

## 4. 학생 화면

| Index | 화면 제목 | 배치할 콘텐츠와 기능 |
|---|---|---|
| 01 | 학습 홈 | 화면 제목을 `오늘의 학습`으로 두고 오늘 날짜와 오늘 할 학습 목록을 한 영역에 모은다. 일일 스케줄에서 자동 배정된 과목·챕터별 학습자료와 문제 수, 순서, `오늘 학습 시작` 버튼을 표시한다. 과목을 직접 고르는 기능은 보조 버튼으로 제공하고, 오늘 일정과 별도 과목 카드로 혼합하지 않는다. 스케줄이 비어 있으면 오늘 학습 미편성 안내와 과목 선택 버튼을 표시한다. 최근 학습 결과와 이어 학습하기는 표시하지 않는다. 진도율·통계 위젯은 두지 않는다. |
| 02 | 과목·챕터 선택 | 과목 탭/목록, 선택 과목의 챕터 목록, 챕터 제목과 간단 설명, 학습 콘텐츠/문제 수 안내, `학습하기` 버튼. 완료 상태나 진도 퍼센트는 표시하지 않는다. |
| 03 | 챕터 학습 | 챕터 제목, 핵심 학습 내용(텍스트/그림/수식), 콘텐츠 출처를 보여준다. 개념에 맞는 짧은 기초 확인 문제를 함께 제공하고, 학생이 답을 선택해 정답을 확인하면 정오와 간단한 설명을 보여준다. 확인 후 `문제 풀기` 버튼으로 본 문제 풀이에 진입한다. |
| 04 | 문제 풀이 | 문제 시작 전에 `기본 문제`와 `심화 문제`를 구분해 선택하는 탭을 제공하고 각 유형의 문제 수를 표시한다. 선택한 유형 안에서 문항 본문과 자료, 선택지 또는 답 입력, 이전/다음, 현재 문항 번호, 답안 제출을 제공한다. 풀이 중 유형을 전환할 수 있으며 유형별 풀이 위치를 구분한다. 정답 제출 전 정답·해설은 감춘다. |
| 05 | 풀이 결과 | 총점, 맞힌 수/전체 문항 수, 문항별 정오와 정답, 간단한 해설, `같은 챕터 다시 풀기`, `다른 챕터 선택`, `학습 홈`. 상세 분석 그래프는 제외한다. |
| 06 | 내 학습 결과 | 날짜순 학습 기록 목록: 과목, 챕터, 풀이 날짜, 점수. 기록 선택 시 결과 화면으로 이동한다. |
| 07 | 학생 정보 | 학생 이름, 학교명, 학년을 확인·수정하고 저장한다. 학교·학년 정보는 학생에게 제공할 학습 콘텐츠와 학사 일정의 기준으로 사용한다. |
| 08 | 학습 일정 | 월간 달력과 일정 목록에서 학교 휴일과 중간·기말고사 일정(시험 기간, 과목)을 등록·수정·삭제한다. 관리자가 편성한 학습 콘텐츠는 유지하면서 개인 학습 날짜·시간을 조정하고, 변경된 일정과 오늘 할 학습을 확인한다. |

## 5. 학부모 화면

| Index | 화면 제목 | 배치할 콘텐츠와 기능 |
|---|---|---|
| 01 | 자녀 학습 결과 | 연결된 자녀 선택, 최근 풀이 목록. 각 행/카드에 풀이 날짜, 과목, 챕터, 점수만 표시한다. 기간 및 과목 필터는 선택 기능으로 제공한다. |
| 02 | 결과 상세 | 선택 기록의 과목, 챕터, 풀이 날짜, 총점, 맞힌 수/전체 문항 수. 학부모 기본 화면에는 학생 답안과 상세 오답 분석을 노출하지 않는다. |
| 03 | 자녀 연결·계정 설정 | 자녀 연결 상태, 초대/승인, 보호자 연락 정보, 비밀번호 변경, 로그아웃. |

## 6. 관리자 화면

| Index | 화면 제목 | 배치할 콘텐츠와 기능 |
|---|---|---|
| 01 | 학습 정보 목록 | 과목/학년 필터, 과목과 챕터 목록, 등록된 학습자료·문항 수, 준비/공개 상태, 수정일, 추가/편집 버튼. 과목·챕터 편집으로 이동한다. |
| 02 | 과목·챕터 편집 | 과목명, 학교급/학년, 챕터명, 설명, 정렬 순서, 사용 여부. 추가·수정·비활성화 기능. |
| 03 | 학습자료 편집 | 챕터 연결, 제목, 본문, 그림/수식 첨부, 출처, 공개 상태, 미리보기, 저장. |
| 04 | 문제은행 편집 | 과목·챕터 연결, 문항 유형, 문제 본문, 선택지/정답, 해설, 난이도(선택), 출처, 공개 상태, 학생 화면 미리보기. 파일럿은 객관식부터 시작하고 필요 시 단답형을 추가한다. |
| 05 | AI 학습 콘텐츠 준비 | 과목·챕터별 AI 콘텐츠 생성 상태, 학습자료·문제·정답·해설의 필수 구성 완료 여부, 오류/누락, 미리보기, 관리자 검수 및 승인 상태를 확인한다. 모든 필수 항목이 완료되고 승인된 콘텐츠만 `스케줄 가능` 상태가 된다. |
| 06 | 일일 학습 스케줄 | 날짜·학년·과목별 학습 편성 목록과 달력을 제공한다. AI 콘텐츠 준비 완료 및 관리자 승인 상태인 콘텐츠만 검색·선택해 날짜별로 배정하고, 순서·공개 시간을 설정하며 미리보기·저장·게시·취소·수정할 수 있다. 미완료/미승인 콘텐츠는 선택을 막고 준비 항목을 안내한다. 공휴일은 달력에 표시해 편성 시 참고한다. |
| 07 | 서비스 설정 | 서비스 공지/점검 안내, 가입 허용·점검 모드·시간대 등 기본 설정, 설정 변경 이력을 관리한다. 학생 개인 성적은 노출하지 않는다. |
| 08 | 공통코드 관리 | 사용자 역할, 계정 상태 등 서비스 공통 코드 그룹과 코드값, 표시명, 정렬 순서, 사용 여부를 조회·등록·수정한다. |
| 09 | 메뉴 관리 | 웹 메뉴의 계층 구조, 메뉴명, 경로, 정렬 순서, 사용 여부를 관리한다. |
| 10 | 메뉴 권한 관리 | 역할별 메뉴 접근 및 조회·등록·수정·삭제 권한을 설정한다. 역할에 맞지 않는 메뉴와 데이터는 표시하거나 접근할 수 없도록 관리한다. |
| 11 | 공휴일 관리 | 연도별 법정 공휴일과 임시 휴무일을 등록·수정하고 일일 학습 스케줄 달력에 표시한다. |
| 12 | 사용자 관리 | 이름/이메일 검색, 역할(학생/학부모/관리자), 계정 상태, 가입일, 연결된 학생/보호자 관계, 계정 활성/정지, 역할 변경. 상세 성적 열람은 별도 권한 없이 제공하지 않는다. |

## 8. 파일럿 화면 확인 기준

- 학생과 학부모는 각 회원가입 화면을 통해 계정을 신청할 수 있고, 로그인 화면에서 유형에 맞게 진입할 수 있다.
- 아이디 찾기와 비밀번호 재설정 화면에서 가입자 본인 확인 절차를 진행할 수 있다.
- 학생은 로그인하면 해당 날짜에 배정된 학습 콘텐츠를 학습 홈에서 자동으로 확인하고 바로 학습을 시작할 수 있다.
- 관리자는 AI 생성 및 필수 학습 정보 구성이 완료되고 관리자 승인된 콘텐츠만 일일 학습 스케줄에 편성할 수 있다.
- 일일 스케줄은 날짜별로 게시·수정·취소할 수 있고 공휴일을 달력에서 확인할 수 있다.
- 학생 화면 어디에도 진도율, 학습시간 분석, 랭킹, 시험 대비 대시보드가 나타나지 않는다.
- 학부모는 자녀의 과목·챕터·풀이 날짜·점수를 확인할 수 있다.
- 관리자는 학습자료 제공에 필요한 교육 정보와 문제를 관리할 수 있다.
- 관리자는 시스템 운영 정보와 사용자 계정을 관리할 수 있다.
- 역할에 맞지 않는 메뉴와 데이터는 표시하거나 접근할 수 없다.
