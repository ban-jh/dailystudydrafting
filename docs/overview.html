1.1 추진 배경 및 내역
추진 배경

한국의 중·고등학생들은 학교 수업 외에도 학원, 인터넷 강의, 문제집 등 다양한 학습 수단을 병행하고 있으나, 과목별 핵심 개념을 빠르게 확인하고 본인 수준에 맞는 문제를 즉시 풀어볼 수 있는 통합적이고 접근성 높은 플랫폼이 부족한 실정이다. 특히 AI 기술의 발달로 개인화된 학습 콘텐츠 생성이 가능해졌으나, 기존 서비스들은 고가의 구독 모델이거나 교과과정과 연계되지 않은 일반적인 AI 챗봇에 그치는 경우가 대부분이다.

이에 중·고등학생을 타겟으로 한 Freemium 기반의 학습 보조 플랫폼 "Daily Study"를 개발하여, 교과과정 기반의 과목 요약, AI 맞춤형 문제 출제, 실생활 영어 문장 학습 등을 하나의 서비스로 제공하고자 한다.

핵심 가치: 접근성(Freemium) · 개인화(AI 맞춤 추천) · 효율성(마이크로러닝) · 신뢰성(교과과정 기반)
프로젝트 내역
No 구분 내용
1 프로젝트명 Daily Study (데일리 스터디) — 중·고등학생 학습 보조 플랫폼
2 프로젝트 목적 중·고등학생 대상의 과목 요약, AI 문제 출제, 실생활 영어 문장 학습 기능을 제공하여 학습 효율과 접근성을 향상
3 타겟 사용자 중학생 1~3학년, 고등학생 1~3학년 (총 6학년 군)
4 서비스 형태 웹 애플리케이션 (PWA 지원), 향후 모바일 앱 검토
5 비즈니스 모델 Freemium (무료 기본 기능 + 프리미엄 구독 모델)
6 개발 기간 총 4개 Phase, 약 12개월 (단계적 MVP → 상용화)
7 주요 기술 Spring Boot 4.0 (Java 21), Vue 3, MariaDB 11, Redis, Docker Compose, GLM-5.2 / GPT-4o-mini
8 개발 방식 애자일 스크럼 (2주 스프린트), 단계적 기능 확장

📚
교과과정 연계 신뢰성

🎮
학습 동기 부여
배지, 레벨, 스트릭 등 게이미피케이션 요소로 학습 지속 동기를 유발하고 자기주도학습 습관 형성.
🌐
실용 영어 학습
실생활 상황별 영어 문장과 롤플레이 모드로 시험용 영어를 넘어 실제 소통 능력 향상에 기여.
