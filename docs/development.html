2. 프로젝트 개발 내용
2.1 주요 개발 항목 목록

Daily Study 프로젝트의 주요 개발 항목은 총 6개 대분류로 구성되며, 각 항목은 단계적 Phase에 따라 개발된다.

No 개발 항목 주요 내용 Phase
1 학습 과정 요약 교과목별 단원 핵심 개념/공식/키워드 카드, 학년별 교육과정 매핑, PDF 내보내기 P1
2 문제 관리 시스템 관리자가 AI 생성·크롤링·직접 입력 3가지 방식으로 문제를 미리 생성 → 검수 승인(PUBLISHED) 후 학생에게 제공, 즉시 채점 및 해설, 오답노트 자동 구성 P1 P2
3 실생활 영어 문장 상황별(학교/쇼핑/여행/식당 등) 실용 영어 문장, 하루 1문장 Push, TTS 발음 음원, 롤플레이 모드, 크롤링 수집 + AI 정제 P2
4 학습 대시보드 일일 목표 설정 및 달성 추적, 과목별 학습 시간/정답률/연속 학습일 통계, 주간·월간 리포트 P1 P3
5 게이미피케이션 배지, 레벨, 스트릭 시스템, 학습 동기 부여 요소 P3
6 관리자 페이지 AI 생성 콘텐츠 품질 검수 큐, 크롤링 파이프라인 관리, 사용자 관리, 콘텐츠 관리 P3 P4
2.2 기능별 상세 개발 내용
📖
① 학습 과정 요약 Phase 1
  • 교과목(수학/영어/과학)별 단원 구조 DB 구축
  • 단원별 핵심 개념, 공식, 키워드 카드 뷰
  • 중·고등학교 학년별 교육과정 매핑
  • 요약 카드 PDF 내보내기 기능
  • 마크다운 기반 콘텐츠 렌더링
🤖
② 문제 관리 시스템 P1 P2
  • 3가지 문제 생성 방식: AI 생성(GLM-5.2) / 크롤링 수집+AI 정제 / 관리자 직접 입력(Excel 일괄 업로드 포함)
  • 생성된 모든 문제는 status=PENDING으로 검수 큐에 등록
  • 관리자 검수 → 승인(PUBLISHED) 또는 반려(REJECTED)
  • 승인된 문제만 학생 화면에 노출 — 승인된 문제 풀에서 랜덤/순차 제공
  • 학생은 실시간 AI 생성을 호출하지 않음 — 즉시 채점, 정답/오답 해설 제공
  • 주관식·서술형 AI 채점 (P2), 오답노트 자동 구성 및 재도출
🌐
③ 실생활 영어 문장 Phase 2
  • 상황별(학교/쇼핑/여행/식당 등) 카테고리 분류
  • Jsoup + Selenium 크롤링 수집 파이프라인
  • AI 정제 (GPT-4o-mini) — 문장 검증 및 난이도 분류
  • 하루 1문장 Push 알림
  • TTS 발음 음원 재생
  • 롤플레이 모드 (대화 시뮬레이션)
📊
④ 학습 대시보드 P1 P3
  • 일일 학습 목표 설정 및 달성 추적 (P1)
  • 과목별 학습 시간, 정답률 통계 (P1)
  • 연속 학습일(스트릭) 표시 (P1)
  • 주간·월간 학습 리포트 자동 생성 (P3)
  • 과목별/단원별 약점 분석 (P3)
🏆
⑤ 게이미피케이션 Phase 3
  • 배지 시스템 (학습 milestones별 뱃지 획득)
  • 레벨 시스템 (학습량 기반 레벨업)
  • 스트릭 보너스 (연속 학습 보상)
  • 랭킹/리더보드 (선택적)
✍️
⑥ 관리자 문제 직접 등록 P1
  • 관리자가 객관식/주관식/서술형 문제를 직접 입력 등록
  • 과목·단원·난이도 선택 후 문제/선택지/정답/해설 입력
  • Excel/CSV 일괄 업로드 (대량 문제 등록)
  • 등록 후 즉시 배포 또는 검수 큐 전달 선택
  • AI 생성 문제와 동일한 구조로 저장 (source_type=MANUAL)
  • 문제 수정/삭제/상태 변경 (PUBLISHED/DRAFT/ARCHIVED)
🔧
⑦ 관리자 페이지 P3 P4
  • 관리자 대시보드 (운영 지표)
  • AI 생성 콘텐츠 품질 검수 큐 (P3)
  • 크롤링 파이프라인 관리 (P4)
  • 사용자 관리 (계정 정지/권한)
  • 콘텐츠 관리 (요약/문제/영어 문장 CRUD)
  • 문제 직접 등록 및 관리 (객관식/주관식/서술형)
2.3 개발 단계별 구성
Phase 1 MVP 1~2개월
  • 이메일 회원가입 / 로그인 (Spring Security + JWT)
  • 3과목(수학/영어/과학) 단원 구조 및 요약 콘텐츠
  • 관리자 문제 생성 시스템 — AI 생성(GLM-5.2) / 크롤링 수집 / 직접 입력(Excel 일괄)
  • 문제 승인 워크플로우 — PENDING → PUBLISHED / REJECTED
  • 기본 학습 대시보드 (일일 목표, 학습 시간, 정답률)
Phase 2 기능 확장 2~3개월
  • 실생활 영어 문장 (크롤링 수집 + AI 정제)
  • TTS 음원 연동 (발음 재생)
  • 오답노트 자동 구성
  • 주관식 / 서술형 AI 채점
  • 소셜 로그인 (OAuth2 — 구글/카카오/네이버)
  • 학습 통계 페이지
Phase 3 개인화 및 고도화 3~4개월
  • AI 맞춤형 문제 추천 (학습 패턴 분석)
  • 게이미피케이션 (배지 / 레벨 / 스트릭)
  • 주간·월간 학습 리포트
  • 관리자 페이지 (품질 검수 큐, 콘텐츠 관리)
  • PWA 오프라인 학습 카드
Phase 4 확장 및 상용화 4개월~
  • 전 과목 개설 (국어, 사회, 역사 등)
  • 크롤링 자동화 파이프라인 (Spring Batch)
  • 모바일 앱 검토 (React Native / Flutter)
  • 프리미엄 구독 모델 도입 (결제 연동)
