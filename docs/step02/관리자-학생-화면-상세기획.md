# 관리자·학생 학습 화면 상세 기획

> 기준: 부안중학교 2026학년도 수학 2 교과서(천재교과서 김화경) 목차의 `연립일차방정식과 그 해` 예시. 화면 사례용 목표와 문항은 교사 검토 전 샘플입니다.
>
> 상태: 학습 단계·복습·일정 기획을 화면 기능으로 구체화한 초안. 클릭 가능한 정적 통합 프로토타입은 [학습 화면 프로토타입](../../screen-spec/learning-process.html)이며, 학생 전용 화면은 [학생 학습 프로토타입](../../screen-spec/student-learning.html)입니다.

## 1. 화면 설계 목표

학생 화면의 예시 데이터는 관리자 설정 흐름인 학교 → 학년도/학년 → 과목 → 교과서 판본 → 목차 단원 → 학습 세션/목표 → 검수 완료 단계 콘텐츠 → 게시 일정과 연결해 표현합니다. 현재 HTML은 관리자 프로토타입의 부안중학교 2026학년도 중2 수학 예시를 정적으로 맞춘 시연이며 실시간 저장소 연동은 아닙니다.

- 학생이 오늘 할 새 학습과 복습을 구분하고 바로 시작할 수 있어야 합니다.
- 학습을 중단해도 마지막 단계부터 이어지고 결과가 기록되어야 합니다.
- 복습에는 이유와 원 학습 목표가 표시되고, 학생 답변이 이후 복습 제안에 반영되어야 합니다.
- 관리자는 주간 일정을 편성하기 전에 콘텐츠 단계, 검수, 분량과 대상 학년을 확인할 수 있어야 합니다.
- 일정은 `공통으로 편성된 새 학습/누적 복습`과 `개인별 결과로 생긴 복습`을 구분합니다.

## 2. 역할 및 내비게이션

### 학생

하단 또는 모바일 탭: `오늘` · `과목별 학습` · `주간 계획` · `학습 기록`. 복습은 오늘 화면과 과목별 상태 필터에서 진입합니다.

### 관리자

사이드 메뉴: `운영 요약` · `학습 일정` · `콘텐츠` · `검수` · `학생 진행 현황`.

이번 MVP의 주 흐름은 학생 `오늘 → 과목 선택 → 단원·게시 세션 탐색 → 학습/복습 → 결과`, 관리자는 `기초정보 → 세션 콘텐츠 검수 → 일정 게시 → 진행 현황`입니다. 주간 계획은 날짜별 분량 확인을 위한 보조 화면으로 둡니다.

## 3. 학생 화면 상세

### STU-01 오늘의 학습 (`/dashboard`)

**목적:** 오늘 해야 할 것과 총 예상 시간을 한 화면에 보여줍니다.

**영역 및 표시 항목**

1. 상단 인사말, 날짜, 주간 계획 진입 버튼.
2. 오늘 요약: 복습·새 학습 개수와 총 예상 시간. 시간값은 학생 파일럿 전까지 예시 상태로 표시.
3. `오늘의 복습` 카드 묶음: 우선순위, 이유, 연결 단원, 예상 시간, `복습 시작`.
4. `오늘의 새 학습` 카드 묶음: 과목·단원·목표, 단계 진행, 예상 시간, `시작/이어하기`.
5. 일정이 비었을 때 빈 상태, 조회 실패 때 재시도, 미완료가 있을 때 이어하기 안내.

**수학 예시:** 복습 카드 `연립방정식의 해 조건 떠올리기 · 전날 학습`, 새 학습 카드 `수학 · 연립일차방정식과 그 해 · 두 식을 모두 만족하는 순서쌍을 판별할 수 있어요`.

**동작:** 복습과 새 학습을 각각 시작할 수 있습니다. 한 카드 완료 시 상태와 예상 잔여 시간을 갱신합니다. 복습 대상이 없으면 복습 섹션을 제거하지 않고 `오늘 예정된 복습이 없습니다`로 설명합니다.

### STU-02 과목별 학습 목록 (/subjects)

**목적:** 주간 달력에 묶이지 않고, 학생이 과목별로 게시된 학습을 단원 순서대로 찾아 시작하거나 이어갑니다.

**화면 구조:** 과목 선택 → 교과서 단원(대·중·소단원) → 해당 단원의 학습 세션 목록. 기본 과목은 학교·학년도·학년 편성에서 학생에게 배정된 과목으로 정합니다. 목록은 펼침/접기 가능한 단원 묶음으로 구성하고, 세션에는 이름, 단원, 세션 목표, 학습 유형, 상태, 예정일/마감, 예상 시간을 표시합니다.

**필터:** 학기, 단원, 진행 상태(전체/진행 중/시작 전/완료/복습 필요), 세션명 검색. 기본 정렬은 교과서 단원 순서와 가까운 예정일을 함께 고려합니다. 모바일에서는 과목·상태를 우선 노출하고 학기·단원·검색은 보조 필터로 둡니다.

**상태:** 진행 중은 이어하기, 오늘 예정은 시작, 완료는 다시 보기, 복습 필요는 복습 시작을 제공합니다. 미게시·검수 대기 콘텐츠는 목록에 노출하지 않습니다. 여기서 전체는 학생에게 게시·배정된 학습 전체를 뜻하며 학교 교육과정 전체나 관리자 초안을 뜻하지 않습니다. 예정일 전 세션은 일정 정책에 따라 잠금 또는 예정 상태를 보여줍니다.

### STU-03 복습 세션 (/review/:reviewId)

**목적:** 정답을 보기 전에 기억을 꺼내고, 이해 정도를 기록합니다.

**화면 구성:** 진행 번호/전체 개수, 복습 이유와 원 학습 날짜, 질문 또는 유사 문항, 답 입력/선택, `정답 확인`, 정답·풀이·개념 링크, 난이도 자기 평가.

**상태 흐름:** `응답 전 → 답 제출 → 피드백 → 쉬웠어요/헷갈렸어요/어려웠어요 → 다음 복습일 안내 → 다음 항목`.

**규칙:** 제출 전 정답을 숨깁니다. 오답이면 개념 요점 보기와 쉬운 예시로 이동할 수 있습니다. 같은 개념의 연속 오답이면 동일 문항 반복보다 보충 학습을 제안합니다. 자기 평가는 성적과 분리해 간격 조정 신호로 저장합니다.

### STU-04 새 학습 세션 (/study-sessions/:sessionId)

**단계 표시:** `선수 개념 확인 → 개념·풀이 예시 → 먼저 회상 → 안내된 기초 연습 → 독립 적용 → 마무리`.

**공통 레이아웃:** 과목·단원·세션 이름과 현재 단계, 단계 진행률, 현재 콘텐츠, 이전/계속, 저장된 진행 안내. 작은 화면에서는 한 단계씩 보여줍니다. 각 활동은 `완료`와 `목표 달성 증거`를 따로 기록하며, 열람·제출만으로 이해했다고 표시하지 않습니다.

**연립일차방정식 세션 예시:**

- 선수 확인: 등식의 성질과 한 문자 일차방정식의 해를 확인하는 낮은 부담의 학습 진단.
- 개념 자료·풀이 예시: 두 식을 동시에 만족하는 해의 의미와 대입해 확인하는 예.
- 회상 후 요점: 학생이 해의 조건을 먼저 떠올려 설명하고 정리 자료와 비교.
- 기초 연습: 순서쌍을 두 식에 대입해 해인지 판별하고 오답이면 단계별 힌트 제공.
- 적용 문제: 다른 수치의 문제에 풀이 절차 적용. 첫 응답 후 피드백·풀이 공개.
- 마무리: 오늘 학습 결과, 틀린 개념, 연결된 다음 복습일.

### STU-05 주간 계획 (/schedule/week)

날짜별 `새 학습`과 `복습`을 나눠서 보여줍니다. 과목별 목록과 역할이 겹치지 않도록 이 화면은 날짜별 분량·마감·복습 배치를 확인하는 보조 화면으로 둡니다. 카드에는 과목·학습 목표·원 학습일(복습인 경우)·상태·예상 시간을 표시합니다. 미완료 학습은 사라지지 않고 `이어하기/재배정 필요`로 유지합니다. 일자별·주간 예상 시간을 함께 보여주며, 복습이 비어 있는 날짜는 비어 있음을 명시합니다.

### STU-06 학습 기록 (/learning-records)

**목적:** 완료한 세션, 이어할 학습, 복습 필요 항목을 요약하고 과목별 목록으로 다시 진입하게 합니다.

**표시:** 학년도·과목별 완료 수, 진행 중 세션, 최근 학습일, 개인 복습 예정/완료 상태. 개인 기록은 학생 본인에게 제공하고 보호자·관리자는 권한 범위에 따라 집계만 조회합니다.

## 4. 관리자 화면 상세

### ADM-01 주간 학습 일정 (`/admin/schedules`)

**필터:** 학교, 학년도, 학년, 과목, 주간 날짜, 일정 상태. 콘텐츠 편성 미리보기에는 학생 개별 정보가 섞이지 않도록 공통 계획과 개인 복습을 별도 지표로 표시합니다.

**주간 요약:** 대상 학생 수, 새 학습 세션 수, 공통 누적 복습 수, 하루 평균 시간, 검수 대기/누락 콘텐츠 경고.

**주간 표:** 행은 요일, 열은 새 학습·공통 복습으로 구성합니다. 셀에는 단원, 목표, 콘텐츠 완성 단계 수, 예상 분량, 게시 상태가 보입니다. 셀을 선택하면 우측 편집 패널을 엽니다.

**편집 패널:** 날짜, 대상(학교·학년), 교과서/과목·단원, 학습 목표, 유형(새 학습/공통 복습), 학습 세션, 각 단계에 연결된 콘텐츠, 예상 시간, 게시 상태, 메모.

**동작:** 초안 저장, 날짜 복사, 콘텐츠 연결, 대상 미리보기, 게시. 게시 전에 미검수 콘텐츠·필수 단계 누락·중복 배정·일일 분량 초과를 검증합니다. 개인 복습은 학생의 결과에 따라 자동으로 생기므로 공통 주간표에서 직접 덮어쓰지 않습니다.

### ADM-02 학습 세션/콘텐츠 편성 (`/admin/sessions/:sessionId`)

세션마다 학생 행동 동사 + 대상 개념/기능 + 수행 조건 또는 확인 증거로 된 목표 문장 하나를 둡니다. MVP 진행 지표는 목표 문구로 묶지 않고 세션 ID로 집계합니다. 예: `주어진 순서쌍을 두 식에 대입하여 연립일차방정식의 해인지 판별한다`. `이해한다`처럼 관찰할 수 없는 표현만으로는 목표를 승인하지 않습니다. 단계별 콘텐츠 연결 표에는 학습 단계, 콘텐츠 제목, 유형, 난이도, 문항 수, 예상 시간, 검수 상태, 출처/버전과 이 단계에서 수집하는 목표 증거를 표시합니다.

**필수 검증:** 세션 목표 입력과 콘텐츠 정합성, 학생 노출 가능 상태, 정답·해설 존재, 대상 학년 적합성, 출처 기록, 학습 단계 순서.

### ADM-03 일정 게시 확인 (`/admin/schedules/:id/publish`)

게시 대상·기간·총 분량·과목별 목표와 콘텐츠 검증 결과를 확인합니다. 경고 항목은 해당 편집 위치로 이동하게 합니다. 게시/변경은 관리자 권한을 검사하고 변경자, 시각, 이전 값과 새 값을 기록합니다. 완료 학습 기록은 게시 일정 수정으로 초기화하지 않습니다.

### ADM-04 학생 진행 현황 (`/admin/schedules/:id/progress`)

집계 지표: 새 학습 시작/활동 완료, 복습 예정/완료/지연, 단계별 이탈, 세션별 첫 시도 결과, 힌트·재시도 사용, 일정 간격 뒤 회상 결과, 다른 형태 문항의 적용 결과. 문항 버전·노출 시점도 함께 보아 난이도 차이를 고려합니다. 학습 완료와 목표 달성은 별도 지표로 표시하고, 한두 문항으로 숙달을 판정하지 않습니다. 복습 지연을 성적 저하로 단정하지 않고 예정/완료 상태를 구분하며, 초기에는 학년·과목 집계부터 제공합니다.

## 5. 주요 데이터 연결

`관리자 편성 과목 → 교과서 판본 → 단원 → 세션(목표 문장 1개) → 단계 콘텐츠`는 학생 과목별 목록과 새 학습 흐름을 표현합니다. 일정 배정은 대상/날짜/세션을 연결합니다. 복습 대상은 원 세션 ID와 학생별 풀이 결과에 연결되며, `생성 이유`, `원 학습/문항`, `예정일`, `상태`, `복습 시도 결과`, `다음 예정일`을 기록합니다. 공통으로 편성한 주간 복습과 학생 개인 복습은 생성 주체와 정책을 분리합니다.

## 6. MVP 화면 구현 순서

1. 학생 오늘 화면과 날짜별 카드 상태.
2. 과목 선택 → 단원 계층 → 게시 세션 목록과 필터.
3. 교사 검토·승인된 중2 수학 세션 한 개와 중단 후 이어하기.
4. 오답/힌트 사용 → 학생 복습 후보 생성 → 검증 중인 정책으로 복습 수행 → 결과 기록.
5. 관리자 콘텐츠 검수·주간 일정 게시·학생 미리보기.
6. 학생 주간 계획·학습 기록과 관리자 진행 현황 집계.

## 7. 화면 인수 조건

- 학생이 오늘의 복습과 새 학습의 구분·이유·예상 시간을 파악할 수 있습니다.
- 학생이 과목별로 게시된 학습 목록을 단원 순서대로 탐색하고 학기·단원·상태·검색으로 범위를 좁힐 수 있습니다.
- 초안·검수 대기·미게시 콘텐츠는 학생 목록과 검색 결과에 나타나지 않습니다.
- 주간 계획은 과목별 전체 목록을 대체하지 않고 날짜별 분량과 마감을 확인하는 보조 화면으로 동작합니다.
- 복습 중 정답 공개 전에 먼저 답을 시도할 수 있고, 결과에 따른 다음 행동이 분명합니다.
- 앱을 나갔다 돌아와도 현재 단계와 입력한 학습 진행이 이어집니다.
- 관리자가 게시 전 검수 상태와 빠진 학습 단계를 확인할 수 있습니다.
- 복습 대상이 없거나 미완료 일정이 있어도 빈 화면이나 기록 손실 없이 다음 행동을 안내합니다.
- 일정 수정은 권한 검사와 변경 이력을 남기며 이미 완료된 학습 기록을 보존합니다.
