# 2단계 — 사용자·시장·학습 콘텐츠 조사

> 상태: 저장소·공개 자료 기반 조사 초안. 학생·보호자 인터뷰, 수요 검증, 콘텐츠 권리 확인과 첫 대상 합의는 남아 있습니다.
>
> 기준일: 2026-11-06
>
> 단계 기준: `docs/step/진행-체크리스트.md`의 2단계. 이 체크리스트에서는 1단계가 현재 상태·목표 정리, 2단계가 사용자·시장·학습 콘텐츠 조사입니다. `docs/step/전체-진행-절차.md`의 단계 번호와 다르므로 이 문서는 체크리스트 번호를 따릅니다.

## 1. 요약

현재 프로젝트 문서에서 확인되는 방향은 중학생·고등학생에게 학교·학습 진도에 맞춘 요약과 문제를 매일 제공하고, 오답을 다시 학습하게 하며, 보호자는 연결된 자녀의 진도를 확인하고, 관리자는 콘텐츠와 일정을 운영하는 것입니다. 이는 사용자가 제공한 목표와 저장소 초안이지, 시장 조사나 사용자 인터뷰로 검증된 수요는 아닙니다.

이번 단계의 공개 자료 조사에서 확인한 점은 다음과 같습니다.

- 교육부의 2022 개정 교육과정은 학생의 자기주도성·맞춤형 교육, 학습 과정에 대한 성찰과 책임, 탐구·개념 중심의 깊이 있는 학습을 강조합니다. 제품은 요약을 보여주는 데서 끝나지 않고, 학생이 설명·문제 풀이·오답 복습으로 이해를 확인하도록 설계할 필요가 있습니다. ([교육부 교육과정 발표](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=93459&lev=0&m=0204))
- K-12 디지털 자기조절학습 연구는 계획·수행·성찰을 지원하는 여러 접근을 정리하지만, 동기·감정 측정은 상대적으로 적고 학습자별로 효과적인 지원이 다를 수 있다고 보고합니다. 따라서 스트릭·점수 보상만으로 동기 문제를 해결한다고 가정하지 않습니다. ([K-12 디지털 자기조절학습 체계적 문헌고찰](https://doi.org/10.1016/j.edurev.2026.100782))
- 교육 목적의 저작물 이용 허용은 학교 수업 등 법에서 정한 목적·대상·범위에 따릅니다. 공개된 교재나 웹 자료라는 이유만으로 상업적 학습 서비스의 복제·요약·재배포 권한이 생긴다고 간주할 수 없습니다. 콘텐츠마다 별도 이용 조건 확인이 필요합니다. ([교육저작권지원센터 안내](https://copyright.keris.or.kr/wft/fntLaw))
- 중학생 대상 기존 대안으로 EBS 중학프리미엄이 학년별·교과서별 강좌, 문제 풀이, 학습 관리와 무료 강좌를 제공하고 있습니다. 따라서 단순한 온라인 요약·문제 제공만으로 차별성을 주장하기 어렵고, 학교·학년 일정 기반 제공, 오답의 후속 복습, 실제 부담이 낮은 일일 흐름을 사용자와 검증해야 합니다. ([EBS 중학프리미엄 소개](https://about.ebs.co.kr/kor/elearning/grade?tabVal=middle), [EBS 2026년 서비스 안내](https://global.ebs.co.kr/board/bbs?boardId=31&boardTypeId=1&cmd=view&no=6&option=&pageNo=842&postId=30005377794&searchCondition=title&searchKeyword=))

**권고:** 첫 실험은 중·고등 전체가 아니라 한 학년·한 과목·소수 단원으로 제한합니다. 중학교 1학년 수학을 후보로 둘 수 있지만, 현재 자료만으로 최종 선택할 근거는 없습니다. 학생 접근성과 콘텐츠 제작·검수 여건을 먼저 확인한 뒤 사용자와 결정해야 합니다.

## 2. 조사 범위와 한계

### 조사한 자료

- 저장소의 1단계 초안, 학습 프로세스·관리자 문서, 화면·메뉴 초안
- 교육부의 2022 개정 교육과정 발표 및 학년별 시행 일정
- 국가교육과정정보센터의 지역 교육과정 자료 목록
- 교육저작권지원센터의 교육 목적 저작물 이용 안내
- 디지털 학습 참여·자기조절학습에 관한 체계적 문헌고찰
- 공개된 EBS 중학프리미엄 서비스 소개 자료

### 이번 조사로 확인되지 않은 것

- 학생·보호자·교사 인터뷰, 실제 학습 로그, 설문 응답
- Daily Study의 시장 규모, 고객 확보 가능성, 유료 전환 가능성
- 경쟁 서비스별 최신 세부 기능·가격을 같은 기준으로 비교한 결과
- 특정 학교·지역·교과서와의 제휴 또는 데이터 제공 가능성
- 교재·문제·이미지·영상·외부 사이트 콘텐츠의 개별 라이선스와 재사용 권한
- 내부 운영 인력·예산·콘텐츠 제작량

따라서 이 문서의 사용자 환경과 동기 요인은 저장소에 이미 적힌 서비스 목표, 공개 자료의 일반적인 연구 결과, 검증할 가설을 구분합니다. 일반 연구 결과를 한국 중·고등학생의 실제 수요로 단정하지 않습니다.

## 3. 기존 프로젝트 문서에서 확인된 기준선

| 구분 | 저장소에서 확인되는 내용 | 상태 |
|---|---|---|
| 학생 | 중·고등학생이 진도에 맞는 요약·문제를 학습하고, 틀린 문제를 이후 다시 풀도록 하는 목표 | 사용자 제공 목표를 문서화한 초안 |
| 보호자 | 연결된 자녀의 진도·학습 현황을 조회하는 역할 | 화면·권한 정책 미확정 |
| 관리자 | 학교·학년·과목·단원·일정을 편성하고, AI 생성·허용된 자료 수집·직접 입력 콘텐츠를 검수·게시하는 역할 | 운영 인력·범위 미확정 |
| 학습 흐름 | 오늘 학습 확인 → 요약 읽기 → 문제 풀이 → 결과·해설 확인 → 오답 복습 | 초안 간 완료 기준·복습 시점 불일치 |
| 콘텐츠 범위 | 요약과 문제, 학년·과목·단원·난이도 태그, 출처와 검수 상태 | 실제 콘텐츠 공급원·권한 미확정 |
| 교육과정 | 학교·학년·적용 연도·교과서·단원 체계를 관리하는 안 | 첫 대상 지역·학교·교과서 미확정 |

참고 문서: [1단계 현황·목표·정보구조](../step01/현황-목표-및-정보구조.md), [학습 콘텐츠 운영·학습 프로세스](../../study_process.md), [관리자 기능 초안](../../study_admin.md), [메뉴 구조도](../../메뉴구조도.md).

### 주요 불일치

- 오답 재학습은 사용자 목표에 포함되지만, 일부 기존 화면·아키텍처 초안에서는 후속 기능입니다. 첫 파일럿에 반드시 포함할지 사용자 결정이 필요합니다.
- 학교·학년 일정을 전제로 하면서 어떤 진도(학교 실제 수업, 교육과정 순서, 학생 개인 진도)를 기준으로 삼을지 정해지지 않았습니다.
- 콘텐츠 생성·크롤링 화면은 상세하지만, 게시에 필요한 출처 권한·검수 담당·운영량은 확인되지 않았습니다.
- 체크리스트와 전체 진행 절차서의 단계 번호가 어긋납니다. 이 단계의 번호는 체크리스트 기준으로 표기합니다.

## 4. 사용자 유형과 학습 환경

| 사용자 | 주요 과업 | 예상 환경 — 확인 필요 | 제품 설계 시 주의점 |
|---|---|---|---|
| 학생 — 핵심 사용자 후보 | 오늘 할 학습 확인, 요약 학습, 문제 풀이, 오답 재학습, 진도 확인 | 방과 후·이동 중·가정 등 여러 장소와 기기에서 짧은 학습을 할 수 있다는 가설. 기기·접속 시간·통신 환경은 미조사 | 현재 학교 진도와 자료가 맞는지, 분량과 예상 시간이 보이는지, 중단 후 이어할 수 있는지 확인 |
| 보호자 — 지원 사용자 후보 | 자녀 계정 연결, 오늘 학습 진행과 진도 확인 | 모바일에서 간단한 진행 상태를 확인할 가능성이 있다는 가설. 선호 주기·공개 상세도 미조사 | 자녀 연결·동의·해제와 공개 정보 범위를 정하고, 감시나 압박으로 느껴질 수 있는 표현을 확인 |
| 관리자·콘텐츠 운영자 | 자료 작성·생성·검수, 일정 편성·게시, 오류 대응 | 소수 운영자가 웹 관리자 화면에서 여러 학년·과목의 자료를 준비할 가능성이 있다는 가설. 담당자 수·작업량 미조사 | 검수 대기량, 권한, 출처 확인, 정답 오류 수정, 일정 변경과 이력 보존을 확인 |

**핵심 사용자 시나리오 제안 — 학생**

1. 학생은 오늘 배정된 과목·단원, 완료 여부, 예상 학습량을 확인한다.
2. 짧은 요약에서 목표 개념과 예시를 학습하고 이해 확인 문제를 푼다.
3. 문제를 제출해 정답·해설을 확인하고, 오답은 복습 목록에 남긴다.
4. 정해진 시점에 오답을 다시 풀고 이전 결과와 비교한다.
5. 오늘 완료한 항목과 다음 학습 위치를 확인한다.

이 흐름은 초기 시나리오 제안일 뿐입니다. 화면 조회만으로 요약 학습 완료를 처리할지, 문제 풀이와 오답 복습까지 어떤 상태를 완료로 집계할지 합의가 필요합니다.

**보호자 시나리오 제안:** 자녀를 안전하게 연결한 뒤 오늘 배정·진행·완료 및 최근 과목별 진도를 읽기 전용으로 확인합니다. 개별 답안·정답률·학습 시간 공개는 학생·보호자와 별도 확인합니다.

**관리자 시나리오 제안:** 대상 교육과정과 단원을 확인하고, 권한이 확인된 자료로 요약·문제를 준비합니다. 검수와 승인을 거친 뒤 일정에 편성해 게시하고, 제공 실패나 오류 신고를 확인합니다.

## 5. 매일 학습 동기와 중단 요인

### 공개 연구에서 얻은 설계 시사점

- K-12 디지털 자기조절학습에 대한 2026년 문헌고찰은 준비·수행·성찰 단계의 인지·동기·감정 지원을 다룹니다. 연구는 인지 과정 기록에 비해 동기·감정 측정이 적고, 학습자별 접근이 필요한 영역은 아직 연구가 제한적이라고 보고합니다. 제품 지표를 접속 횟수만으로 구성하기보다 목표 확인, 학습 진행, 회고와 부담을 함께 살펴볼 근거가 됩니다. ([문헌고찰 DOI](https://doi.org/10.1016/j.edurev.2026.100782))
- 학습자 통제 수업의 체계적 검토는 동기 관련 결과에 작은 긍정 효과를 보고했지만, 인지 학습 결과는 혼재했다고 정리합니다. 중등 맥락에서 조직·콘텐츠 선택권이 도움이 될 수 있다는 결과도 있지만, 이는 특정 Daily Study 기능의 효과를 보장하지 않습니다. 선택권은 학생 인터뷰로 적정 범위를 확인할 가설입니다. ([학습자 통제 수업 체계적 검토](https://doi.org/10.1016/j.lmot.2022.101850))
- 온라인 학습에 대한 2024년 체계적 검토는 유연성·자기 속도 학습의 장점과 함께, 참여 저하·고립·교사/또래 상호작용 부족 등의 문제를 보고합니다. 연구 대상과 수업 조건이 다양하므로 한국 중·고등학생에게 동일하게 적용된다고 단정하지 않습니다. ([온라인 학습 참여·성과 검토](https://link.springer.com/article/10.1007/s44217-024-00253-0))

### 제품에서 검증할 가설

| 영역 | 검증할 가설 | 확인 방법 |
|---|---|---|
| 시작 동기 | 오늘 해야 할 일과 예상 시간이 짧고 분명하면 첫 학습을 시작하기 쉬워진다 | 학생에게 실제 과제량·예상 시간 표시 전후의 시작 경험을 질문하고 프로토타입으로 비교 |
| 지속 동기 | 현재 위치와 다음 학습을 보여주면 스스로 진도를 관리하는 데 도움이 된다 | 학습 계획을 직접 정하는지, 앱이 추천하는 계획 중 무엇이 편한지 확인 |
| 피드백 | 정답 여부뿐 아니라 오답 이유와 다시 풀 시점을 제공하면 복습 가치가 높아진다 | 최근 오답 사례를 바탕으로 해설·재풀이 방식 평가 |
| 중단 요인 | 학교 수업 진도·교과서와 배정 콘텐츠가 다르면 신뢰와 재방문이 낮아진다 | 실제 학교/학년/교과서 조합별 진도 사례 비교 |
| 중단 요인 | 과도한 분량, 어려운 설명, 중단 후 저장 실패는 학습을 멈추게 한다 | 학습 세션 인터뷰와 시나리오 사용성 확인 |
| 관계·동기 | 보호자 공개와 연속 학습 표시가 학생에 따라 지원 또는 압박이 될 수 있다 | 학생·보호자를 따로 인터뷰해 공개 범위와 문구 선호를 비교 |
| 보상 | 스트릭·점수·배지의 효과가 학생·상황에 따라 다를 수 있다 | 기본 흐름과 선택적 보상 프로토타입을 비교하고 부담감도 기록 |

## 6. 첫 대상 학년·목적·과목 후보

교육부 고시 제2022-33호는 2022 개정 교육과정을 2025년 중·고등 1학년, 2026년 2학년, 2027년 3학년에 순차 적용하도록 정합니다. 2026년 현재 학년을 대상으로 콘텐츠를 만들 경우 적용 교육과정 연도를 함께 관리해야 합니다. ([교육부 교육과정 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&m=0404&opType=N&s=moe&statusYN=W))

2022 개정 교육과정은 자기주도성·학생 맞춤형 교육, 학습에 대한 성찰, 탐구와 개념 기반의 깊이 있는 학습을 강조합니다. 고등학교는 선택 과목의 폭이 넓어 학년·학교·선택 과목을 특정하지 않으면 한 가지 공통 학습 계획을 만들기 어렵습니다. 중학교 또한 지역·학교 교육과정 편성 자료가 존재하므로 전국 단일 진도를 가정하기 어렵습니다. ([교육부 교육과정 방향](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=93459&lev=0&m=0204), [NCIC 지역 교육과정 자료](https://ncic.re.kr/edu/localCurriculum/list.do?page=1&searchCategory=031))

| 후보 | 기대할 수 있는 검증 포인트 | 비용·위험 | 상태 |
|---|---|---|---|
| 중학교 1학년 수학 | 개념 요약 → 풀이 → 오답 재학습을 한 흐름으로 연결하기 적합하다는 가설 | 문제의 정답·해설 검수 부담, 교육과정/학교 진도 편차 | 파일럿 후보. 수요·콘텐츠 확보 여부 미확인 |
| 중학교 1학년 영어 | 어휘·문법·독해 등 짧은 단위 콘텐츠 후보, 기존 문서의 영어·TTS 관련 자료 활용 가능성 | 대상 하위 영역을 먼저 좁혀야 하며 오디오·교재 문장 권리 점검 필요 | 비교 후보. 사용자 수요 미확인 |
| 중학교 과학 | 단원별 개념과 확인 문제 조합을 시험할 수 있다는 가설 | 교육과정별 단원 범위·용어·정답 검수가 필요 | 비교 후보. 운영 자료 미확인 |
| 고등학교 과목 | 고등 학생의 구체적 학습 목적을 확인한 뒤 선택과목/학년을 맞춰 설계 가능 | 선택과목·학년도·학교별 차이가 큼. 넓은 범위 동시 지원 시 콘텐츠·운영 부담 증가 | 초기 범위로 확정하지 않음 |

**선택 기준 제안:** 사용자 모집 가능성, 학생이 겪는 문제의 중요도, 교육과정/교과서 매핑 가능성, 원문과 문항의 권리 확보 가능성, 요약·문제·해설을 지속 제작할 인력, 오류를 검수할 수 있는 전문가를 기준으로 후보를 비교합니다. 현재 어떤 후보도 선택된 사실은 아닙니다.

**첫 학습 목적 제안:** 학교 진도에 맞춘 핵심 개념 확인 → 관련 문제 풀이 → 오답 재학습. 수능 대비, 전 과목 개인화, 고급 AI 튜터링은 첫 파일럿에서 별도 결정 전까지 범위로 가정하지 않습니다.

## 7. 시장 대안과 초기 차별화 가설

이번에는 시장 규모나 결제 의향을 조사하지 않고, 프로젝트가 마주할 대표적인 대안의 일부만 공개 자료로 확인했습니다.

| 대안 | 공개 자료에서 확인한 제공 방식 | Daily Study가 검증해야 할 질문 |
|---|---|---|
| EBS 중학프리미엄 | 학년별 강좌, 교과서/과목별 강좌, 문제 해설·학습 관리 등. EBS의 서비스 안내는 중학생을 위한 무료 강좌와 학습 관리 기능을 소개합니다. | 강의 중심으로 충분하지 않은 학생이 매일 짧은 과업·오답 복습을 원하는지, 실제로 학교 진도 일정형 흐름을 차별점으로 보는지 |
| 학교·교사 제공 수업자료 및 학습 플랫폼 | 학교 수업·학급 단위 자료와 과제를 제공할 수 있음. 현재 이 프로젝트는 학교 도입이 결정되지 않았음 | 학생 개인 서비스인지 학교·교사 도구인지 먼저 확인해야 함 |
| 문제집·학원·개인 학습 | 이미 학생의 교과 복습·문제 풀이·피드백에 쓰이는 대안. 이번 문서에서는 개별 제품별 비교 미실시 | 학생이 기존 학습을 대체할지 보완할지, 추가 일일 학습을 감당할 수 있는지 |

따라서 “AI”, “매일 콘텐츠”, “오답 관리”만으로 시장 차별성을 주장하지 않습니다. 초기 차별화 가설은 **학교/학년/단원에 맞춘 작은 오늘 학습 묶음, 요약과 문제의 직접 연결, 학생별 오답 재방문, 부담이 적은 진도 확인**입니다. 이 가설은 실제 학생과 보호자가 중요하게 여기는지 테스트해야 합니다.

교육저작권지원센터 안내상 학교 수업 목적의 저작물 이용은 대상과 범위에 제한이 있고, 교과용도서·수업·수업지원은 각각 목적과 조건이 다릅니다. 학교 밖 상업 서비스에 동일 예외가 자동 적용된다고 볼 수 없습니다. 교과서의 공개·수업 목적 이용 허용을 상업적 웹 서비스의 콘텐츠 권한으로 확대 해석하지 않고, 원문을 저장·요약·문항화·재배포하기 전에 자료별 권리와 필요한 이용허락을 확인해야 합니다. 이는 법률 판단이 아니라 출시 전에 확인해야 할 운영 조건입니다. ([교육저작권지원센터 — 저작권 법·제도](https://copyright.keris.or.kr/wft/fntLaw))

**콘텐츠 등록 시 보존할 메타데이터 제안:** 출처 이름·URL·저자/권리자, 이용 허락 근거·라이선스·조건, 수집/작성일, 원문과 파생 콘텐츠 관계, 적용 교육과정·과목·학년·단원, 학습 목표, 정답·해설 검수자/일자, 연령 적합성 결과, 게시·수정·철회 이력.

## 9. 콘텐츠 정확성·연령 적합성·교육과정 연계 기준

### 초안 품질 기준

1. **교육과정 매핑:** 교육과정 버전·학년도·학교급·학년·과목·단원과 학습 목표를 기록한다. 학교별 편성 또는 교과서별 차이가 있으면 해당 매핑을 별도로 표시한다.
2. **학습 목표:** 한 묶음에서 학생이 할 수 있어야 하는 행동을 관찰 가능한 표현으로 쓴다. 예: 개념을 설명한다, 풀이 절차를 적용한다, 오답 이유를 찾는다.
3. **내용 정확성:** 요약의 정의·예시, 문항의 정답·보기, 해설의 계산·근거가 일치하는지 과목 담당자가 확인한다.
4. **연령·수준 적합성:** 문장 길이, 용어, 선수 지식, 문제 단계와 민감한 예시를 학년과 학습 수준에 맞춰 확인한다.
5. **피드백 가치:** 정답만 보여주지 않고 풀이 근거와 대표 오답이 틀린 이유를 알려준다. 틀린 학생을 낙인찍는 언어를 쓰지 않는다.
6. **권리·출처:** 근거와 이용 조건이 기록되지 않은 자료는 학생에게 게시하지 않는다.
7. **AI 산출물:** 생성 과정과 무관하게 사실, 문항, 정답, 해설, 편향·연령 적합성, 권리를 검수한다. 승인 전 학생 노출을 막는다.
8. **정정·철회:** 오류 신고, 게시 중단, 수정 버전, 이미 풀이한 기록에 미치는 영향과 학생 안내를 정한다.

2022 개정 교육과정이 자기주도성, 개념·탐구 중심 학습, 학습 과정의 성찰을 강조하므로 정답 암기형 자료에 치우치지 않도록 하되, 과목별 성취기준을 확인한 뒤 문항 수준과 학습 목표를 정합니다. ([교육부 발표](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=93459&lev=0&m=0204))

### 지역·학년도 차이

교육부 고시는 중·고등학교 2022 개정 교육과정을 학년별로 순차 시행합니다. NCIC에는 시·도교육청의 지역 교육과정 편성·운영 자료도 별도로 제공됩니다. 따라서 콘텐츠 분류에 학년만 두기보다 최소한 **교육과정 버전·적용 학년도·학교급·학년·과목·단원**을 둡니다. 학교·교과서 편차를 학생별 일정에 실제 반영할지는 운영 모델과 공급 데이터 확인 후 결정합니다. ([교육부 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&m=0404&opType=N&s=moe&statusYN=W), [NCIC 지역 교육과정](https://ncic.re.kr/edu/localCurriculum/list.do?page=1&searchCategory=031))

## 11. 사용자 검증 계획

시장·사용자 가설을 결정으로 바꾸려면 첫 사용자 모집 후 다음을 확인합니다. 미성년자 대상 조사와 기록은 보호자 동의 및 개인정보 최소 수집 절차를 마련한 뒤 진행합니다.

### 권장 참여자와 질문 주제

- 학생: 중·고등학교급과 학년이 다른 학생을 소수 모집해 최근 일주일의 공부 시작·중단 경험, 평소 학습자료, 오답 복습 경험, 휴대기기와 하루 가능한 시간을 묻습니다.

- 교사/콘텐츠 검수자: 학교·교과서 진도 편차, 핵심 콘텐츠 오류 유형, 안전한 자료 사용 경로, 검수 가능한 주간 분량을 확인합니다.
- 콘텐츠 운영 담당 후보: 원자료 확보·권리 확인·문항 작성·검수에 필요한 실제 시간과 병목을 확인합니다.

1. 최근 실제로 공부를 시작했던 때를 이야기해 주세요. 시작할 때 무엇을 했고, 무엇이 어려웠나요?
2. 최근 하려다 미룬 학습이 있었다면 무엇 때문에 멈췄나요?
3. 학교에서 배우는 진도와 집에서 사용하는 학습 자료는 어떻게 맞추나요?
4. 틀린 문제를 다시 보는 방법과 다시 보지 않게 되는 이유는 무엇인가요?
5. 요약과 문제를 한 세트로 제공하면 어떤 점이 편하고 불편할까요?
6. 한 번의 학습에 실제로 어느 정도 분량/시간이 적절할까요? 그렇게 생각하는 근거는 무엇인가요?
7. 학습 결과를 보호자가 어디까지 보는 것이 도움이 되고, 어디부터 부담인가요?
8. 이 서비스를 쓰지 않고 기존 문제집·강의·학교 플랫폼을 선택할 만한 이유는 무엇인가요?

질문은 의견보다 최근 행동 사례를 먼저 묻고, 특정 기능 사용을 유도하지 않습니다. 인터뷰 뒤에는 후보 학년·과목에 대한 실제 매핑 자료와 권리 확인 가능성을 대조합니다.

## 12. 아직 필요한 결정

1. 첫 핵심 사용자는 중학생과 고등학생 중 누구인가? 하나의 파일럿 학년으로 좁힐 수 있는가?
2. 첫 학습 목적은 학교 수업 복습, 시험 대비, 자기주도 학습 중 무엇인가?
3. 첫 과목과 단원을 정할 때 수요, 수업 진도 연결, 콘텐츠 권리, 검수 인력 중 어떤 조건을 우선할 것인가?
4. 일정은 교육과정 단원 순서, 학교의 실제 수업 진도, 학생의 개인 진도 중 무엇을 우선 기준으로 할 것인가?
5. 요약·문제·해설·오답 재학습을 파일럿의 한 흐름에 모두 포함할 것인가?
6. 보호자에게 제공할 정보와 학생의 동의·연결·해제 절차는 무엇인가?
7. 콘텐츠를 자체 작성, 라이선스 계약, 명시적 재사용 허가 자료, AI 보조 중 어떤 조합으로 공급할 것인가?
8. 콘텐츠 정확성과 권리를 확인할 담당자, 승인 조건, 정정 책임자는 누구인가?
9. 하루 분량과 예상 시간은 어느 수준부터 실험할 것인가?
10. 사용자 검증에서 성공/실패를 판단할 첫 지표와 관찰 기간은 무엇인가?

## 13. 단계 완료 상태

이번 산출물은 저장소 초안과 공개 자료를 묶은 검토 가능한 조사 초안입니다. 다음 항목이 남아 있어 체크리스트의 2단계 완료나 첫 핵심 사용자 합의로 표시하지 않습니다.

- 학생·보호자·교사 인터뷰 및 학습 환경 검증
- 수요와 경쟁 대안에 대한 비교 검증
- 첫 학년·과목·학습 목적 선택
- 자료별 사용 권한과 지속 공급 가능성 확인
- 사용자와 조사 결과 및 첫 핵심 사용자 합의
