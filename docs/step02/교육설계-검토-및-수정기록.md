# 교육·학습 설계 검토 및 수정 기록

> 검토일: 2026-11-06
>
> 검토 방식: 교육·학습 설계 관점과 평가·학습과학 관점을 분리한 두 AI 리뷰어의 독립 검토, 저장소 문서 대조, 교육부·출판사·교육 연구 가이드 확인.
>
> 한계: 검토자는 실제 현직 교사나 자격을 확인한 교육 전문가가 아닙니다. 이 문서는 전문가 관점의 AI 검토 기록이며, 학교 현장 검토나 전문 자문 완료로 간주할 수 없습니다.

## 1. 종합 판단

현재 기획은 학생의 오늘·주간 학습, 새 학습과 복습 분리, 콘텐츠 검수, 일정 게시 등 **제품 흐름의 초안**으로는 유용한 구조를 갖췄습니다. 그러나 최초 버전은 학습 목표의 증거 기준, 선수 지식 분기, 풀이 예시와 독립 연습 사이의 발판, 복습 큐 운영 정책이 충분하지 않아 교육적으로 검증된 설계라고 보기 어렵습니다.

또한 화면 프로토타입의 수학 예시인 `집합`은 부안중학교 2026학년도 수학 2(천재교과서 김화경) 목차 사례와 맞지 않습니다. 학교 교과서 목록의 수학 2 채택 정보를 출판사 목차와 대조해 샘플 주제를 `연립일차방정식과 그 해`로 변경했습니다. 실제 수업 진도나 담당 교사의 목표는 여전히 확인이 필요합니다.

## 2. AI 리뷰에서 나온 핵심 의견과 반영

| 우선순위 | 리뷰 의견 | 반영 내용 |
|---|---|---|
| P0 | 집합 예시가 목표 학교의 중2 수학 교과서 단원이라는 근거가 없음 | 학습 계획과 화면 문서의 대표 예시를 연립일차방정식으로 변경. 실제 수업 진도와 목표는 교사 확인 사항으로 표시 |
| P1 | 개념 설명 전 선수 개념 확인이 없고 학생 필요에 따른 경로 분기가 약함 | 등식의 성질·일차방정식의 해 등 낮은 부담의 사전 확인 단계를 추가. 평가 점수 대신 설명·힌트 제공에 활용하도록 명시 |
| P1 | 중요 요점 카드가 수동 재읽기로 끝날 수 있음 | 요점 공개 전에 학생이 먼저 기억을 떠올리고 자신의 답과 정리 자료를 비교하는 순서로 변경 |
| P1 | 풀이 예시에서 독립 문제로 넘어가는 단계가 급함 | 풀이 예시와 단계별 힌트가 있는 안내 연습을 추가하고, 오답 뒤에는 풀이 설명과 다른 유사 문제 제공 |
| P1 | 활동 완료와 목표 숙달 판정의 경계가 불분명할 수 있음 | 읽음/제출에 따른 활동 완료와 여러 증거를 바탕으로 한 목표 달성을 별도 상태로 정의. 한두 문항만으로 숙달을 선언하지 않도록 명시 |
| P1 | 1·3·7일은 구체적인 근거가 있는 고정 주기로 오인될 수 있음 | 이를 가설 후보로만 남기고, 정책 설정화·교사 검토·지연 회상 파일럿을 선행하도록 보완. 자기평가 하나로 간격 결정 금지 |
| P1 | 복습이 밀릴 때 중복·이월·우선순위·새 학습 차단 규칙이 없음 | 같은 목표의 예약/오답 복습 중복 제거, 지연 복습이 새 학습을 자동 차단하지 않는 원칙 추가. 상한과 이월 규칙은 파일럿 결정값으로 분류 |
| P2 | 오래 고민한 시간은 어려움이나 오개념을 안정적으로 나타내지 않음 | 초기 복습 신호에서 반응 시간 추정을 제거하고 첫 정오·힌트 사용·자기평가처럼 해석 가능한 신호 사용 |
| P2 | 완료율·정답률만으로 학습 효과를 판단하기 어려움 | 목표별 첫 응답, 힌트·재시도, 지연 회상, 다른 표현 문항 적용, 콘텐츠 버전/노출 시점 지표를 추가 |
| P2 | 하루 20~25분 및 주 5일 예시가 학생에게 적정하다고 검증되지 않음 | 소요 시간은 파일럿 전 가정으로 표시. 실제 중2 학생과 교사에게 체감 분량을 확인해야 함 |

## 3. 참고한 근거 및 범위

- 교육부 고시는 2026년 3월부터 중학교 2학년에 2022 개정 교육과정을 시행한다고 명시합니다. 이것만으로 학교별 실제 수업 진도까지 알 수는 없습니다. [교육부 2022 개정 교육과정 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0)
- 부안중학교 공식 교과서 목록에서 수학 2가 천재교과서 김화경 저자판으로 제시된 것을 확인했고, 출판사 페이지의 목차에서 `Ⅰ 수와 식`, `Ⅱ 부등식과 연립방정식`, `Ⅲ 일차함수`, `Ⅳ 삼각형과 사각형의 성질`, `Ⅴ 도형의 닮음과 피타고라스 정리`, `Ⅵ 경우의 수와 확률`을 확인했습니다. 해당 목차에는 집합이 없습니다. [부안중학교 2026 교과서 목록](https://buan-m.goeay.kr/buan-m/na/ntt/selectNttInfo.do?bbsId=1352&mi=3653&nttSn=1298618), [천재교과서 수학 2 평가문제집 목차](https://m.chunjaetext.co.kr/product/%EC%A4%91%ED%95%99-%EC%88%98%ED%95%99-2%EA%B9%80%ED%99%94%EA%B2%BD-%ED%8F%89%EA%B0%80%EB%AC%B8%EC%A0%9C%EC%A7%91/6992/category/59/display/1/)
- 교육 연구 자료는 연습 시험/회상과 시간을 두고 분산하는 연습을 유망한 전략으로 설명합니다. 간격은 목표 보유 기간, 학습 결과와 상황에 맞춰 조절해야 하므로 이 자료들은 1·3·7일을 고정 정답으로 보증하지 않습니다. [AERO 회상·간격 학습 가이드](https://www.edresearch.edu.au/guides-resources/practice-guides/spacing-and-retrieval-practice-guide-full-publication), [Dunlosky 외, 학습 기법 연구 검토](https://journals.sagepub.com/doi/10.1111/j.1539-6053.2013.01026.x)

## 5. 실제 교사·전문가 검토가 필요한 결정

1. 부안중학교 2학년의 실제 수업 진도, 각 학기/기간의 단원 순서.
2. 연립일차방정식 샘플의 선수 개념, 용어와 기호, 목표 문장, 설명/풀이의 정확성.
3. 단계별 문항 수, 난이도 상승, 힌트와 오답 설명의 적절성.
4. 목표 달성 여부를 판단할 문항 종류와 여러 증거의 최소 기준.
5. 복습 후보 간격, 하루 분량, 주말/결석/미완료 처리와 학생이 느끼는 부담.
6. 학습 예상 시간과 화면 문구가 실제 중2 학생에게 자연스러운지.

이 검토 뒤에도 콘텐츠 파일럿에서 정답률만 보지 않고 지연 회상, 새로운 문항에의 적용, 학생이 느낀 난이도와 학습 시간도 함께 살핀 뒤 운영 정책을 결정해야 합니다.
