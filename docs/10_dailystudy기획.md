# Daily Study 서비스 기획·설계안

- 작성일: 2026-11-13
- 상태: 초기 제품 기획안
- 목적: 학교 수업 진도에 맞춘 매일 학습과 학생별 학습 상태 파악, 시험 대비를 하나의 서비스로 제공한다.

## 1. 제품 방향

Daily Study는 학생이 학교에서 실제로 배우는 단원과 속도를 기준으로 매일의 학습을 계획하고 실행하도록 돕는 중·고등학생용 학습 서비스다. 학생은 개념을 정리하고 문제를 풀며, 시스템은 결과를 성취기준·개념·문항 유형별로 누적해 다음 학습을 조정한다. 중간·기말고사 전에는 시험 범위에 맞춘 핵심 정리와 충분한 연습 세트를 제공한다.

### 제품 원칙

1. **학교 진도 우선**: 학년·학기·과목뿐 아니라 교과서와 실제 수업 단원, 진도 날짜를 학생이 설정한다. 학교마다 단원 순서와 속도가 다를 수 있으므로 표준 진도를 강제하지 않는다.
2. **매일 실행 가능한 분량**: 과목별 가용 시간과 학습 요일을 반영해 오늘 할 일을 제안하고, 미완료 학습은 학생이 원하는 방식으로 재배치한다.
3. **학습 상태를 근거와 함께 표시**: 진도 완료율만 보여주지 않고 개념별 정답률, 최근 풀이, 재학습 필요 여부와 근거를 함께 제시한다.
4. **오답은 재학습 자산**: 틀린 문항, 풀이 과정, 정답 이유, 오답 원인, 재도전 기록을 저장해 별도 오답 노트와 복습 일정에 연결한다.
5. **AI는 초안을 만들고 관리자가 통제**: AI 생성 요약·문제·해설·일정은 검증 상태를 거쳐 배포한다. 관리자는 수정, 승인, 반려, 버전 관리와 즉시 비공개 처리를 할 수 있다.
6. **교육과정·저작권을 준수**: 공식 성취기준과 허가된 콘텐츠를 기준으로 연결하고, 교과서·기출문제 원문을 무단 복제하지 않는다.

## 3. 대상 사용자와 권한

### 학생

- 학년, 학교급, 학기, 과목, 교과서, 학교 실제 진도와 주간 학습 가능 시간을 설정한다.
- AI 추천 스케줄을 확인하고 직접 이동·추가·삭제·완료 처리한다.
- 요약을 학습하고 문제를 풀며 결과와 해설을 확인한다.
- 오답 노트에서 미복습·복습 중·완료 상태를 관리하고 다시 푼다.
- 시험 날짜와 과목별 범위를 등록해 시험 대비 계획을 조정한다.

### 관리자/콘텐츠 편집자

- 교육과정, 학년·과목·단원·개념 및 교과서 매핑을 관리한다.
- AI 생성 학습 일정, 단원 요약, 문제·정답·해설을 검수하고 수정·승인·반려한다.
- 승인된 콘텐츠만 학생에게 공개하며 버전, 수정자, 검수 이력을 확인한다.
- 문항 중복·오류·신고, 사용 중지, 재검토 대상을 관리한다.
- 학생 개인 성적 열람은 업무상 필요한 최소 권한으로 분리하고 접근 이력을 남긴다.

### 보호자(후속 범위)

학생 동의와 정책에 따라 주간 학습 현황과 일정한 요약 지표를 열람한다. 상세 답안이나 민감한 학습 기록은 기본적으로 제공하지 않는다. 초기 MVP에서는 학생/관리자 기능을 우선하고 보호자 기능은 후속 단계로 둔다.

## 4. 핵심 사용자 흐름

1. **초기 설정**: 학교급·학년·학기 → 과목·교과서 선택 → 학교에서 현재 배우는 단원과 다음 진도일 입력 → 목표와 학습 가능 요일·시간 설정.
2. **진단 및 계획 생성**: 선택 과목의 짧은 진단 또는 학생이 이미 아는 정도 입력 → 진도와 목표일을 반영해 AI가 주간 계획 초안 생성 → 학생이 검토·수정 후 확정.
3. **매일 학습**: 오늘의 과목·단원 확인 → 핵심 개념 요약 → 짧은 확인 문제 → 수준별 문제 풀이 → 결과 및 오답 원인 확인 → 오답 노트 저장 및 다음 복습 예약.
4. **학교 진도 변경**: 학생이 학교 진도표에서 단원·날짜 변경 → 아직 시작하지 않은 계획을 재배치 → 이미 완료한 학습과 시험 일정은 보존 → 변경 내역 안내.
5. **시험 대비**: 과목·시험일·범위 선택 → 취약 개념 진단 → 핵심 요약과 일별 복습·문제 풀이 계획 생성 → 단원별/혼합 실전 세트 → 시험 직전 오답 우선 복습.
6. **관리자 콘텐츠 운영**: 생성 요청/배치 생성 → 자동 형식·정답 일관성 검사 → 편집자 검수 → 승인·배포 → 학생 반응/오류 신고 모니터링 → 수정 시 새 버전 발행.

## 5. 기능 요구사항

### 5.1 학교 진도와 학습 스케줄

- 교육과정 표준 진도는 추천 기준으로만 제공하며, 학교 실제 진도는 별도 데이터로 저장한다.
- 일정 항목은 과목, 단원/개념, 날짜, 예상 시간, 학습 활동(개념/문제/복습), 출처, 상태, 우선순위를 가진다.
- 반복 학습일, 시험일, 휴일, 학습 가능 시간과 완료된 항목을 고려해 계획한다.
- 학생은 항목을 이동·추가·삭제하고 목표 시간·요일을 바꿀 수 있다. 변경 후 충돌이나 밀린 분량을 설명하고 재계획을 제안한다.
- AI 재계획은 미완료 학습을 임의로 삭제하지 않는다. 계획 변경 전후를 비교하고 되돌릴 수 있다.
- 관리자 화면에서는 교육과정 기본 일정 템플릿을 편집할 수 있지만 학생 개인 일정에는 학생의 확정 없이 강제 적용하지 않는다.

### 5.2 단원 요약과 수업 내용 연결

- 요약은 성취기준, 핵심 개념, 필수 용어, 대표 예시, 흔한 오개념, 스스로 확인할 질문으로 구조화한다.
- 학생/관리자가 수업 날짜와 진도 범위를 기록해 학교 수업 내용과 서비스 단원을 연결한다.
- AI는 승인된 교육과정 자료와 라이선스가 확인된 출처를 사용한다. 근거가 부족한 내용은 생성하지 않거나 검토 필요로 표시한다.
- 요약은 쉬운 설명/시험 직전 압축/개념 간 관계 등 목적별 보기로 제공하고, 출처와 콘텐츠 버전을 노출한다.

### 5.3 문제은행

문항별 필수 메타데이터: 과목, 학교급·학년·학기, 교육과정 버전, 단원·하위 개념, 성취기준, 문항 유형, 난이도, 정답률(충분한 응답 누적 후), 예상 풀이 시간, 정답, 해설, 오답 선택지별 설명, 출처·라이선스, 검수 상태, 버전, 공개 범위.

- 유형: 객관식, 단답형, 서술형(초기에는 규칙 기반/관리자 채점 우선), 자료 해석형 등.
- 난이도·개념·시험 범위·문항 수를 조건으로 세트 구성 및 무작위 출제한다.
- 같은 학생에게 단기간에 동일 문항이 반복되지 않도록 노출 이력을 반영한다.
- AI 생성 문항은 정답 유일성, 선택지 중복, 풀이 검증, 교육과정 태그, 편향·부적절 표현을 점검하고 관리자 승인 전에는 기본 비공개한다.
- 기존 문제은행/기출문항 사용은 출처와 이용 허가가 확인된 경우로 제한한다. 생성 문항도 표절·유사도 점검과 검수가 필요하다.

### 5.4 풀이 기록과 학습 상태

- 풀이 기록: 문항/버전, 학생 답, 정오, 시도 횟수, 풀이 시간, 힌트 사용, 답안 제출 시각, 채점 방식.
- 단원별 상태는 진도와 이해도를 분리한다. 예: 학습 전 / 학습 중 / 복습 필요 / 기준 달성.
- 이해도는 최근 문항 결과와 성취기준 커버리지를 기반으로 계산하며, 데이터가 적으면 “판단 중”으로 표시한다.
- 학생에게 단순 등급보다 “어떤 개념의 어떤 유형에서 어려움이 있었는지”와 추천 다음 행동을 제공한다.
- 서술형 AI 채점은 초기에는 참고 피드백으로만 표시하고, 최종 성적 산출에 단독 사용하지 않는다.

### 5.5 오답 노트

- 오답은 자동 저장하며 과목·단원·개념·날짜·오답 원인·복습 상태로 필터링한다.
- 오답 원인은 학생 선택(개념 부족, 계산 실수, 문제 해석, 시간 부족, 추측 등)과 AI 추정값을 구분한다.
- 원문 문항과 답안, 해설, 당시 학습 자료 버전을 연결하고, 재도전 기록을 누적한다.
- 오답만 모아 다시 풀기, 아직 해결하지 못한 오답만 보기, 시험 범위 오답만 보기, 유사 문항 풀기를 제공한다.
- 재도전 정답이어도 일정 간격 뒤 확인 문제로 유지할 수 있으며 학생이 완료 처리 및 재복습을 조정한다.

### 5.6 시험 대비 모드

- 학생이 과목별 시험 날짜와 범위를 지정한다. 학교별 시험 범위는 관리자가 추정하지 않는다.
- 계획은 남은 날짜, 단원 분량, 취약 개념, 가능한 학습 시간, 오답 복습량을 반영한다.
- 단원 핵심 정리, 개념 확인, 대표 유형, 고난도/서술형(해당 과목), 혼합 실전 세트를 제공한다.
- 풀이 결과에 따라 취약 단원에 시간을 재배분하고 시험 직전에는 새 개념보다 핵심 회상·오답 재도전을 우선 추천한다.
- 시험 종료 후 결과(선택 입력)를 반영해 다음 학기 계획의 보정 근거로 쓴다.

## 6. AI 생성·검수 운영 설계

### 생성 흐름

1. 입력 범위 지정: 교육과정 버전, 학교급, 과목, 학년, 단원/성취기준, 난이도, 출력 형식, 허용 출처.
2. AI 초안 생성: 일정, 요약 또는 문항과 정답·해설을 구조화된 데이터로 생성한다.
3. 자동 검증: 필수 필드, 태그 일치, 문항 중복, 정답/해설 논리 일관성, 표현 안전성, 출처·라이선스 확인 여부 검사.
4. 관리자 검수: 미리보기에서 수정, 승인, 반려 사유 입력, 재생성, 과거 버전 비교를 한다.
5. 배포: 승인된 버전을 대상 학생/교육과정에 공개한다. 발행 시점, 편집자, 승인자, 프롬프트/모델 버전, 변경 로그를 기록한다.
6. 사후 관리: 오류 신고·낮은 정답률 급변·콘텐츠 신고가 발생하면 검토 대기 또는 즉시 비공개할 수 있다.

### 상태 모델

`초안 → 자동검증 통과/실패 → 검수 대기 → 수정 요청 또는 승인 → 게시 → 개정/중지`

생성 콘텐츠는 관리자 권한으로 바로 게시할 수 있는 옵션을 제한된 운영자에게만 허용하고, 기본값은 승인 후 게시다. 학생 데이터는 모델 학습에 자동 재사용하지 않으며 별도 동의·정책 결정 전에는 학습 입력으로 보내지 않는다.

## 7. 정보 구조와 화면

### 학생 영역

- 홈/오늘 학습: 오늘의 계획, 남은 시간, 학교 진도, 이어하기, 밀린 계획 조정.
- 내 학습 계획: 주간·월간 달력, 과목별 진도, 계획 편집, 시험 일정.
- 과목·단원: 교과서/교육과정 선택, 단원 트리, 핵심 요약, 성취기준별 학습.
- 문제 풀이: 문항, 진행 상태, 힌트, 답 제출, 해설, 다음 추천.
- 오답 노트: 필터, 재도전, 복습 상태, 오답 원인 수정.
- 학습 리포트: 과목/단원별 진도·이해 상태, 최근 추이, 데이터 부족 안내.
- 설정: 학교 진도, 목표, 학습 요일·시간, 알림, 계정/개인정보.

### 관리자 영역

- 교육과정/학교급/교과서/단원/성취기준 관리.
- 학교 진도 템플릿과 스케줄 규칙 관리.
- AI 생성 작업 및 검수 대기열.
- 요약·문제은행 편집, 버전 비교, 태그/라이선스 관리.
- 사용자·권한·신고·콘텐츠 품질 대시보드와 감사 로그.

## 8. 데이터 개체 초안

| 개체 | 주요 관계/필드 |
|---|---|
| User, Role, Consent | 학생/관리자 역할, 연령·보호자 동의 상태, 접근 권한 |
| CurriculumVersion, Subject, Grade, Unit, Concept, AchievementStandard | 교육과정 버전을 기준으로 한 표준 학습 구조 |
| Textbook, TextbookUnitMapping | 교과서 판/출판사와 표준 단원 간 매핑 |
| StudentCourse, SchoolPacing, ExamScope | 학생이 선택한 과목, 실제 진도 날짜, 시험일·범위 |
| StudyPlan, PlanItem, PlanRevision | 계획과 일정 항목, 생성 근거, 학생 수정 이력 |
| Summary, Question, Choice, Answer, Explanation | 학습 자료와 문항 구조, 출처·버전·검수 상태 |
| ContentReview, ContentVersion, AuditLog | 승인/반려, 수정 diff, 작업자·시각·근거 |
| Attempt, WrongAnswer, MasterySnapshot | 풀이 원본 기록, 오답 복습 상태, 시점별 숙련도 추정 |
| Recommendation, Notification | 추천 이유, 노출/수락/무시 기록, 알림 설정 |

학생 일정/응답 원본과 관리자 콘텐츠 버전을 분리한다. 삭제·정정 요청을 처리할 수 있도록 보존기간, 익명화, 백업 복구 정책을 제품 출시 전에 확정한다.

## 9. 비기능 요구와 운영 기준

- **보안·개인정보**: 미성년자 서비스에 맞는 법률 검토, 최소 수집, 보호자 동의 절차 검토, 암호화, 역할별 접근 제어, 접근 로그, 계정·기록 삭제 절차를 설계한다.
- **접근성·기기**: 모바일 우선 반응형 웹을 기본으로 하고 키보드 조작, 충분한 대비, 수식/표 대체 설명을 고려한다.
- **콘텐츠 품질**: 정답과 해설의 독립 검수, 교육과정 버전 태깅, 오류 신고 처리 SLA를 운영 정책으로 정한다.
- **설명 가능성**: 추천마다 반영한 진도·정답 이력·시험일까지의 기간을 짧게 설명하고 학생이 계획을 수정할 수 있게 한다.
- **신뢰성**: AI 생성/추천 실패 시 승인된 기본 콘텐츠와 학생 편집 스케줄로 정상 학습이 가능해야 한다.
- **저작권**: 교과서 본문, 기출 문항, 참고서 문항은 라이선스 확인 없이 저장·변형·AI 입력·배포하지 않는다.

## 10. MVP 범위와 단계

### MVP (1차 출시)

- 중학교 또는 특정 학년·과목군부터 시작하는 좁은 범위의 교육과정/단원 데이터.
- 학생의 교과서·실제 진도·학습 가능 시간 설정과 주간 계획 생성/수정.
- 승인된 단원 요약과 객관식·단답형 문항은행, 자동 채점·해설.
- 오늘 학습, 풀이 이력, 자동 오답 노트, 재도전.
- 관리자 콘텐츠 CRUD, AI 초안 생성, 검수·승인·반려, 버전·감사 로그.
- 단원/과목별 기본 리포트와 데이터 부족 상태 표시.

### 2차

- 중간·기말 대비 모드, 범위별 실전 세트와 잔여일 재계획.
- 문제 유형·난이도 다양화, 유사 문항 추천, 취약 개념 보강.
- 고등학교 학년/선택과목 구조 확대, 복수 교육과정 버전 대응.

### 3차

- 서술형 답안 첨삭 보조, 보호자 요약, 교사/학원 그룹 관리(수요와 정책 검토 후).
- 충분하고 적법한 풀이 데이터가 축적된 뒤 개인화 추천 고도화.

### MVP에서 제외

- 무검수 AI 문제의 자동 공개.
- 공식 성적 예측이나 전국 석차 단정.
- 광범위한 교과서 원문/기출문제 무단 수집.
- 학생 풀이 이력을 동의 없이 생성형 AI 학습에 이용하는 기능.

## 11. 성공 지표

- **활성화**: 가입 학생 중 과목·진도·학습시간 설정 완료율.
- **학습 습관**: 주간 계획 수립률, 계획 대비 완료율, 주간 학습일 수.
- **학습 효과**: 성취기준별 사전/사후 확인 문제 변화, 오답 재도전 해결률, 일정 기간 뒤 유지율.
- **콘텐츠 품질**: 관리자 승인률, 검수 수정률, 문항 오류 신고율, 신고 처리 시간.
- **학생 주도성**: 제안 계획 수락·수정률, 일정 변경 후 완료율, 추천 사유 이해도 설문.

단순 문제 풀이 수를 성과로 단정하지 않는다. 지표는 학습 기회와 사용성 개선을 위해 활용하고 학생 간 서열화에 사용하지 않는다.

## 12. 초기 결정이 필요한 제품 질문

구현 착수 전 기획 범위를 확정할 때 결정한다.

1. 1차 출시 학교급·학년·과목을 어디까지로 제한할지.
2. 교육과정/교과서 메타데이터의 공식 제공처와 문제 콘텐츠 라이선스를 어떻게 확보할지.
3. 학생 직접 가입과 보호자 동의·계정 연결 방식을 어떻게 둘지.
4. 학생 답안과 학습 기록의 보존 기간, 삭제 요청, 관리자 열람 정책을 어떻게 정할지.
5. AI 사용 모델/비용/개인정보 처리 경계와 관리자 승인 책임을 어떻게 운영할지.
