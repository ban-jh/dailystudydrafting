5.2 역할 분담
No 역할 인원 주요 책임 및 업무
1 프로젝트 스폰서 1명 프로젝트 예산 승인, 주요 의사결정, 방향성 수립, 마일스톤 승인
2 프로젝트 매니저 (PM) 1명 전체 일정/범위/품질 관리, 스프린트 계획, 이해관계자 커뮤니케이션, 리스크 관리
3 백엔드 개발자 2명 Spring Boot REST API 개발, MyBatis SQL 매핑, 인증(JWT/OAuth2), Spring Batch 크롤링 파이프라인, DB 설계
4 프론트엔드 개발자 2명 Vue 3 SPA 개발, TailwindCSS + daisyUI 컴포넌트, Pinia 상태관리, PWA 구현, 반응형 UI
5 AI 엔지니어 1명 GLM-5.2 / GPT-4o-mini 프롬프트 엔지니어링, AI 응답 파싱 및 검증, 콘텐츠 품질 로직 설계
6 데이터 엔지니어 1명 Jsoup/Selenium 크롤링 파이프라인, 데이터 정제, MariaDB 스키마 관리, Redis 캐싱 전략
7 인프라 엔지니어 1명 Docker Compose 구성, Nginx 설정, CI/CD 파이프라인, 서버 모니터링, 배포 자동화
8 QA 엔지니어 1명 테스트 케이스 작성, 통합/회귀 테스트, 성능 테스트, AI 콘텐츠 품질 검수 프로세스
총 인원: 10명 (스폰서 1 + PM 1 + 백엔드 2 + 프론트엔드 2 + AI 1 + 데이터 1 + 인프라 1 + QA 1)
