Daily Study — 전체 프로세스 플로우

사용자(학생/학부모) · 관리자 화면 구성 및 학습 프로세스

사용자 (학생 / 학부모)

  • • 학생: 대시보드 → 과목 → 단원 목차 → 요약/문제 → 풀이 → 결과 → 오답
  • • 학부모: 자녀 학습 현황, 주간/월간 리포트 조회
  • • 실시간 AI 호출 없이 승인된 문제만 풀이
  • • 학습 통계: 정답률, 학습시간, 스트릭

관리자

  • • 과목·단원·요약 CRUD 등록 관리
  • • 문제 생성 3가지: AI(GLM-5.2) / 크롤링 / 직접 입력(Excel)
  • • 검수 큐: PENDING → 승인(PUBLISHED) / 반려(REJECTED)
  • • 승인된 문제만 학생에게 제공
  • • 사용자 관리, 크롤링 파이프라인 관리

공통 인프라

  • • Spring Security + JWT: 학생/학부모/관리자 권한 분기
  • • MariaDB: 사용자·문제·학습로그 영구 저장
  • • Redis: 캐싱, 세션, Rate Limiting
  • • AI: GLM-5.2(한국어), GPT-4o-mini(영어), Edge TTS
  • • Spring Batch: 크롤링 자동화, 통계 집계
