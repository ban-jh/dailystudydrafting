이벤트 설명

1단원 목록
  • GET /api/subjects/{subjectId}/units 호출 — 단원 목록 조회
  • 각 단원의 학습 상태 표시 (완료 ✓ / 학습 중 / 미학습)
  • 단원 클릭 시 해당 단원의 핵심 개념 플래시카드 로드
  • 학습 완료 단원은 체크 아이콘 + 회색 처리
2핵심 개념 플래시카드
  • GET /api/units/{unitId}/summaries 호출 — 핵심 개념 카드 목록
  • 카드 좌우 스와이프로 이전/다음 카드 이동
  • 카드 탭(클릭) 시 앞면(질문) ↔ 뒷면(설명) 뒤집기
  • 진행 표시: 현재 카드 번호 / 전체 카드 수
  • 학습 완료 시 STUDY_LOG에 기록 (type=SUMMARY)
3PDF 내보내기 버튼
  • 클릭 시 GET /api/units/{unitId}/export-pdf 호출
  • 현재 단원의 핵심 개념 요약을 PDF 파일로 다운로드
  • 다운로드 진행률 표시
  • 완료 시 "PDF가 다운로드되었습니다" 토스트
