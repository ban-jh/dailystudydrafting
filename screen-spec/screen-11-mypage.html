이벤트 설명

1프로필 정보
  • GET /api/users/me 호출 — 프로필 정보 표시
  • 이름, 이메일, 학년, 레벨, 누적 XP 표시
  • 프로필 아바타는 기본 이모지 (Phase 3에서 이미지 업로드)
  • 이름 클릭 시 수정 가능
2학년 설정
  • 드롭다운: 중1~중3, 고1~고3
  • 변경 시 PUT /api/users/grade 호출
  • 학년 변경 시 추천 학습 콘텐츠 자동 갱신
  • 변경 완료 토스트 표시
3알림 설정
  • 학습 리마인더: 매일 정해진 시간 학습 알림 (토글 ON/OFF)
  • 주간 리포트: 매주 월요일 학습 요약 알림 (토글 ON/OFF)
  • PUT /api/users/settings 호출 — USER_SETTINGS 테이블 업데이트
  • 알림 시간 설정 (리마인더 ON 시 시간 선택 가능)
4배지 현황
  • GET /api/users/badges 호출 — 획득 배지 + 미획득 배지 표시
  • 획득 배지: 컬러 아이콘, 미획득: 🔒 잠금 아이콘
  • 배지 클릭 시 획득 조건 안내
  • BADGE 테이블 + USER_BADGE 조인 데이터
5TTS 자동재생 설정
  • 실생활 영어 화면 진입 시 자동 TTS 재생 여부 토글
  • PUT /api/users/settings 호출 — USER_SETTINGS.tts_autoplay
  • ON: 영어 문장 로드 시 자동 음성 재생
  • OFF: 수동 🔊 버튼 클릭 시에만 재생
6로그아웃 버튼
  • 클릭 시 "로그아웃 하시겠습니까?" 확인 다이얼로그
  • 확인 시 로컬 스토리지 JWT 토큰 삭제
  • 로그인 화면(SCR-01-LOGIN)로 이동
  • POST /api/auth/logout 호출 — 서버 세션 정리
