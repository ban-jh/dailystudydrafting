02 회원가입 SCR-02-SIGNUP 이메일/비밀번호/이름/학년/관심과목을 입력하여 회원가입

05 단원 요약 SCR-05-UNIT-SUMMARY 선택한 과목의 단원 목록과 핵심 개념 플래시카드 화면
06 문제 풀이 설정 SCR-06-QUIZ 과목/단원/난이도/유형/문제수를 설정하여 문제를 푸는 화면

08 오답노트 SCR-08-WRONG-ANSWERS 틀린 문제 목록과 재풀이/해설 기능을 제공하는 화면
09 실생활 영어 SCR-09-ENGLISH 오늘의 영어 문장과 상황별 카테고리, TTS 재생 기능
10 학습 통계 SCR-10-STATISTICS 과목별 정답률 차트, 학습시간, 연속 학습일 통계 화면
11 마이페이지 SCR-11-MYPAGE 프로필/학년/알림/배지/TTS 설정을 관리하는 화면
