이벤트 설명

1단원 요약 버튼 클릭 (목차에서)
  • 단원 목차(SCR-05-UNIT-LIST)에서 '📖 단원 요약' 버튼 클릭 시 이 화면으로 이동
  • GET /api/units/{unitId}/summaries 호출 — 단원 핵심 개념 요약 데이터 조회
  • 단원 제목, breadcrumb(학년 > 과목 > 단원) 표시
2PDF 다운로드 버튼
  • 헤더 우측 '📄 PDF' 버튼 또는 본문 '📄 PDF 다운로드' 버튼 클릭
  • GET /api/units/{unitId}/export-pdf 호출 — 현재 단원 요약을 PDF로 다운로드
  • 다운로드 진행률 표시, 완료 시 "PDF가 다운로드되었습니다" 토스트
3핵심 개념 카드
  • 단원의 핵심 개념을 카드 형태로 표시 (제목 + 설명)
  • 좌측 파란색 테두리로 개념 카드 강조
  • 768px 이상에서 2열 그리드 배치
4공식 박스
  • 다크 배경(#0B1026)에 주요 공식을 강조 표시
  • 공식 제목, 공식 본문(모노스페이스), 설명 포함
  • GET /api/units/{unitId}/formulas — 공식 데이터 조회
5예시
  • 녹색 배경 박스에 함수인 경우/함수가 아닌 경우 예시 표시
  • 개념 이해를 돕는 구체적인 수학 예제 제공
  • ✅ / ❌ 이모지로 직관적인 판별 결과 표시
6핵심 포인트
  • 주황색 배경 박스에 시험에 자주 나오는 포인트 정리
  • 번호(①②③④)가 매겨진 핵심 체크 사항 목록
  • 학습 완료 시 STUDY_LOG에 기록 (type=SUMMARY)
7이 단원 문제 풀기 버튼
  • '✏️ 이 단원 문제 풀기 →' 버튼 클릭 시 문제 풀이 화면(SCR-07-QUIZ)으로 이동
  • 현재 단원 ID를 파라미터로 전달 (unitId)
  • 승인된 문제(status=PUBLISHED)만 문제 풀에서 즉시 제공
8목차로 돌아가기 버튼
  • '📋 목차로 돌아가기' 버튼 클릭 시 단원 목차(SCR-05-UNIT-LIST)로 이동
  • 이전 화면(단원 목차)으로 복귀 — 뒤로가기와 동일
