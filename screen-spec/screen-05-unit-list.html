이벤트 설명

1과목 카드 클릭 시 이 화면으로 이동
  • 과목 목록(SCR-04-SUBJECTS)에서 과목 카드 클릭 시 이 화면으로 이동
  • GET /api/subjects/{subjectId}/units 호출 — 단원 목록 조회
  • 페이지 타이틀: "{과목명} — 단원 목차"
  • 서브타이틀: "N개 단원 · M개 완료 (P%)" 형식
2단원 요약 버튼 클릭
  • 각 단원 카드의 '📖 단원 요약' 버튼 클릭 시
  • 단원 요약 화면(SCR-06-UNIT-SUMMARY)으로 이동 (unitId 파라미터 전달)
  • 해당 단원의 핵심 개념, 공식, 예시, 핵심 포인트 표시
3문제 풀기 버튼 클릭
  • 각 단원 카드의 '✏️ 문제 풀기' 버튼 클릭 시
  • 문제 풀이 화면(SCR-07-QUIZ)으로 이동 (unitId 파라미터 전달)
  • 승인된 문제(status=PUBLISHED)만 문제 풀에서 즉시 제공
4진행률 % 표시
  • 각 단원 카드에 진행률 배지(100% / 60% / 0%) 표시
  • 진행률 바(색상: 완료=초록, 진행중=파랑, 미진행=회색)
  • GET /api/subjects/{subjectId}/progress — 단원별 진행률 데이터
  • 현재 학습 중인 단원은 파란색 테두리로 강조
5스크롤하여 전체 단원 확인
  • 단원 카드 목록을 스크롤하여 전체 단원 확인 가능
  • 각 단원 카드: 번호, 제목, 진행률 배지, 진행률 바, 버튼 2개
  • 카드 hover 시 그림자 효과로 인터랙션 피드백
