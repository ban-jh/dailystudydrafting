이벤트 설명

1오늘의 영어 문장
  • GET /api/english/today 호출 — 매일 1개 문장 자동 갱신
  • 영어 문장 + 한국어 해석 + 상황 태그 표시
  • 🔊 버튼 클릭 시 TTS 음성 재생
  • TTS 엔진: Edge TTS(무료) / OpenAI TTS(고품질) 설정 가능
  • 사용자 설정의 TTS 자동재생 여부에 따라 진입 시 자동 재생
  • 3-layer 캐싱: Redis → DB → 파일시스템
2상황별 카테고리
  • 6개 카테고리: 카페 / 편의점 / 학교 / 전화 / 식당 / 여행
  • 카테고리 클릭 시 GET /api/english?category={} 호출
  • 해당 카테고리의 문장 목록으로 화면 전환
  • 각 문장마다 개별 TTS 재생 버튼
3추가 문장 목록
  • 선택한 카테고리 내 문장들을 스크롤 목록으로 표시
  • 각 문장별 TTS 재생 버튼 (🔊)
  • 북마크 기능 — 저장한 문장은 마이페이지에서 확인
  • 문장 출처: AI 생성(GPT-4o-mini) + 웹 크롤링(Spring Batch)
4롤플레이 버튼
  • AI와 대화형 영어 연습 모드 시작
  • 상황(카페 주문 등)에 맞는 역할극 시나리오 제공
  • 사용자 응답 → AI(GPT-4o-mini) 응답 → TTS 재생
  • 대화 종료 후 피드백 및 교정 제안
