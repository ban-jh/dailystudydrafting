이벤트 설명

1주간/월간 토글
  • 주간(W) / 월간(M) 기간 토글 버튼
  • 선택 변경 시 모든 통계 데이터 재조회
  • GET /api/statistics?period=weekly|monthly 호출
  • 기본값: 주간
2과목별 정답률 차트
  • 6개 과목별 정답률을 수평 바 차트로 표시
  • 과목별 색상 적용 (국어#F43F5E / 수학#3B82F6 / 영어#6366F1 / 과학#10B981 / 사회#F59E0B / 역사#92400E)
  • GET /api/statistics/accuracy-by-subject 호출
  • 과목 클릭 시 해당 과목 상세 통계로 드릴다운
3학습 시간 차트
  • 요일별 학습 시간을 세로 막대 차트로 표시
  • GET /api/statistics/study-time-daily 호출
  • 주간: 월~일 / 월간: 1~4주
  • 막대 탭 시 상세 시간 툴팁
  • STUDY_LOG 테이블 기반 데이터
4요약 통계
  • 연속 학습일: STUDY_LOG 기준 연속 접속일 수
  • 총 학습시간: 기간 내 누적 학습 시간
  • 평균 정답률: 기간 내 전체 문제 정답률
  • 각 카드 클릭 시 상세 분석 화면 확장
