이벤트 설명

1과목 선택
  • 6개 과목 중 택 1 (국어/수학/영어/과학/사회/역사)
  • 선택 시 해당 과목의 단원 목록 로드
  • 필수 선택 — 미선택 시 다음 단계 비활성화
2단원 선택
  • GET /api/subjects/{id}/units 호출 — 단원 드롭다운
  • 전체 단원 옵션 포함 (단원 전체 문제 풀기)
  • 필수 선택 — 미선택 시 "단원을 선택하세요" 에러
3난이도 선택
  • 쉬움 / 보통 / 어려움 3단계
  • 기본값: 보통
  • 선택한 난이도에 해당하는 status=PUBLISHED 문제만 필터링
4문제 유형 선택
  • 객관식(4지선다) / 주관식(단답형) 선택
  • 기본값: 객관식
  • 주관식 선택 시 AI 채점 (GLM-5.2) 적용
5문제 수 슬라이더
  • 5~20문제 범위에서 슬라이더로 조절
  • 기본값: 10문제
  • 선택한 범위 내에서 랜덤 출제
  • 문제 풀에 충분한 문제가 없을 경우 최대 가능 수 표시
6문제 풀기 버튼
  • POST /api/quiz/generate 호출 — 설정 조건으로 문제 세트 생성
  • 승인된(status=PUBLISHED) 문제 풀에서만 출제
  • AI 생성 문제(source_type=AI) + 관리자 직접 등록 문제(source_type=MANUAL) 혼합
  • 로딩 화면 표시 후 문제 풀이 진행
  • 문제 풀이 완료 후 결과 화면(SCR-07-QUIZ-RESULT)로 이동
