이벤트 설명

1정답률 요약
  • GET /api/quiz/attempts/{attemptId}/result 호출
  • 정답 수 / 전체 문제 수 + 백분율 표시
  • 그라데이션 카드로 시각적 강조
  • 정답률 80% 이상 시 축하 애니메이션
2오답 목록 + 해설
  • 틀린 문제만 필터링하여 표시
  • 문제 본문, 내 답, 정답 비교 표시
  • "해설 보기" 클릭 시 GET /api/quiz/{quizId}/explanation 호출
  • 해설은 AI(GLM-5.2)가 생성한 상세 풀이 과정
  • 틀린 문제는 자동으로 오답노트(QUIZ_ATTEMPT.is_wrong=true)에 등록
3XP 획득 표시
  • 맞춘 문제당 10 XP 계산 (정답 × 10)
  • POST /api/users/xp 호출 — 사용자 XP 누적
  • 레벨업 시 추가 축하 메시지 표시
  • 배지 획득 조건 충족 시 배지 알림
4다음 문제 풀기 버튼

  • 문제 풀이 설정(SCR-07-QUIZ)로 이동하여 설정 변경 가능
  • "결과 공유하기" 옵션 (선택)
