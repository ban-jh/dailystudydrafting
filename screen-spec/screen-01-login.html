이벤트 설명

1이메일 입력 필드
  • 이메일 형식 검증 (xxx@xxx.xxx 패턴)
  • 빈 값 체크 — 입력하지 않은 경우 "이메일을 입력하세요" 에러
  • 포커스 시 테두리 #4555FF 강조
  • 입력값은 trim 처리 후 서버 전송
2비밀번호 입력 필드
  • 최소 8자 이상 입력 검증
  • 마스킹 처리 (••••••••)
  • 눈 아이콘 클릭 시 입력값 표시/숨김 토글
  • 빈 값 체크 — 입력하지 않은 경우 "비밀번호를 입력하세요" 에러
3로그인 버튼
  • 클릭 시 입력값 검증 → POST /api/auth/login 호출
  • 성공 시 JWT 토큰 발급, 로컬 스토리지 저장
  • 성공 시 대시보드(SCR-03-DASHBOARD)로 이동
  • 실패 시 "이메일 또는 비밀번호가 올바르지 않습니다" 에러 메시지 표시
  • 요청 중 버튼 비활성화 + 로딩 스피너 표시
4회원가입 링크
  • 클릭 시 회원가입 화면(SCR-02-SIGNUP)로 이동
  • 호버 시 밑줄 애니메이션
