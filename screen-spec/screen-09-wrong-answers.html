  • 과목 필터: 전체 / 국어 / 수학 / 영어 / 과학 / 사회 / 역사

2오답 목록

  • 오답 횟수가 높을수록 상단 정렬 옵션
  • 무한 스크롤 또는 더보기 버튼으로 페이지네이션
  • 빈 목록 시 "오답이 없습니다. 문제를 풀어보세요!" 안내
3해설 보기 버튼
  • GET /api/quiz/{quizId}/explanation 호출
  • 모달/하단 시트로 상세 해설 표시
  • AI 생성 풀이 과정 + 정답 도출 순서
  • 관련 단원 개념 요약 링크 제공
4재풀이 버튼
  • 해당 오답 문제를 다시 풀 수 있는 화면으로 이동
  • 재풀이 시 새로운 QUIZ_ATTEMPT 생성
  • 정답 시 오답 목록에서 제거 (is_resolved=true)
